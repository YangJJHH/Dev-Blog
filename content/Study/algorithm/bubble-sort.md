## 버블 정렬

버블정렬은 현재 원소와 다음 원소를 비교하여 서로 자리를 바꾸는 방법의 정렬이다.

아래 그림을 보게 되면 현재 원소와 다음원소를 비교하여 큰것을 오른쪽으로 보내고 있다.

![[29-1.png]]

한번의 과정을 거치면 가장 큰 원소가 가장 마지막에 온다는게 보장이 된다.

이처럼 (n-1), (n-2)... 번의 비교연산을 통해 모든 원소를 정렬할 수 있다.

결국 시간 복잡도는 (n-1) + (n-2) ... 1의 연산의 합이니깐, n*(n-1)/2 이므로 O(N^2)이 된다.

코드를 보자

```cpp
 // 버블 정렬
int arr[5] = { 7,1,3,4,2 };
int n = 5;
for (int i = 0; i < n; ++i)
{
    for (int j = 0; j < n - 1 - i; ++j)
    {
        if (arr[j] > arr[j + 1])
            std::swap(arr[j], arr[j + 1]);
    }
}
```
