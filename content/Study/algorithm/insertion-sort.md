## 삽입정렬

삽입정렬은 두번째 원소부터 진행하며, 현재 원소를 앞에 정렬된 원소들 중 적절한 위치에 삽입하는 방법의 정렬 알고리즘이다.

동작 방식은 아래와 같다.

![[30-1.gif]]

*출저 : 위키피디아*

예제코드

```cpp
 // 삽입 정렬
int arr[5] = { 7,1,3,4,2 };
int n = 5;
for (int i = 1; i < n; ++i) // 두번쨰 원소부터 시작
{
    int tmp = arr[i]; // 현재 원소 임시저장
    int j;
    for (j = i-1; j >= 0; --j)
    {
        if (arr[j] > tmp) // 현재 원소보다 크다면, 현재 원소자리에 비교한 원소 저장
        {
            arr[j + 1] = arr[j];
        }
        else // 현재 원소보다 작다면 삽입할 자리를 찾음
            break;
    }
    arr[j + 1] = tmp; // 원소삽입
}
```
