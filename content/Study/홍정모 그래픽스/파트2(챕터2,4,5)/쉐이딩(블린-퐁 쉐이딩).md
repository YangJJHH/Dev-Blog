- 쉐이딩
	조명과 재질의 상호작용을 고려해서 색을 결정하는것

쉐이딩의 방법에는 2가지 있다.
1.  버텍스 쉐이더에서 버텍스 색을 결정한 뒤, 픽셀 쉐이더에서 Interpolation을 통해 결정하는 법
2. 쉐이딩 알고리즘 방법 자체를 픽셀 쉐이더에서 구현하는법

픽셀 수에 비해서 버텍스 수가 훨씬 적기 때문에 1번 방법이 성능적으로는 더 빠르다. 대신 랜더링의 상세도는 좀 떨어진다. 요즘에는 GPU가 많이 빨라졌기 때문에 픽셀쉐이더에서 쉐이딩을 하는 편이 많다. 이번 실습에서는 픽셀 쉐이더에서 쉐이딩 하는 방법을 사용한다(2번).


## Ambient
ambient 는 픽셀쉐이더에서 그냥 컬러값을 리턴시켜주면 된다.
ambient가 필요한 이유는 아래 그림을 보면됨. 실제로 반사광까지 모두 추적하여 색을 결정하는 것은 매우 많은 연산이 필요하기 때문에 비슷한 효과를 내며 성능을 떨어트리지 않게 ambient를 사용

## 블린-퐁 모델
![[Pasted image 20240821220419.png]]

퐁 모델을 개선한 모델. 기존 퐁 모델은 완전 반사 벡터 R벡터를 구해 R내적V로 Specular를 구했다. 하지만 R벡터를 구하는 과정 자체가 계산이 많았기 때문에 R벡터를 사용하는대신 H벡터
즉 HalfWay Vector를 사용해 속도를 높였다.

원래는 여기서 Color도 BaryCentricCoordinate을 통해 구했지만 이번에는 퐁-블린 쉐이딩을 통해 그려볼것이기 때문에 픽셀쉐이더를 통해 컬러값을 얻어온다. **그리고 잘 보면 픽쉘쉐이더로 전달되는 좌표값이 월드상 좌표를 통해 현재 픽셀이 월드상 어떤 좌표에 해당하는지 Interpolation해서 넘기고 있다.** 이래야지 픽쉘쉐이더에서 퐁-블린 모델에 필요한 월드상 좌표를 알 수 있음

퐁-블린은 픽쉘세이더의 ComputeDirectionlight를 통해 구해진다.
```cpp
vec4 MyPixelShader(const PSInput psInput) {

    vec3 eye = vec3(0.0f, 0.0f, -1.0f);
    vec3 toEye = glm::normalize(eye - psInput.position);
    vec3 color = ComputeDirectionalLight(constants.light, constants.material,
                                         psInput.normal, toEye);
```
HalfWay Vector를 구하기 위해 물체의 표면에서 눈으로의 방향벡터를 구한다.


이 안에서는 표면에 들어가는 빛의 세기를 표면의 노멀과 라이트 방향의 각도를 통해 구해준다.
```cpp
vec3 ComputeDirectionalLight(Light L, Material mat, vec3 normal, vec3 toEye) {

    // 계산에 사용하는 lightVector는 directional light가 향하는 방향의 반대
    vec3 lightVec = -L.direction;

    // 빛과 표면의 각도로 빛의 세기를 얼마나 받는지 계산
    float ndotl = glm::max(glm::dot(lightVec, normal),0.0f); 
    vec3 lightStrength = L.strength * ndotl;

    // Luna DX12 책에서는 Specular 계산에도
    // Lambert's law가 적용된 lightStrength를 사용합니다.
    return BlinnPhong(lightStrength, lightVec, normal, toEye, mat);
}
```


```cpp
vec3 BlinnPhong(vec3 lightStrength, vec3 lightVec, vec3 normal, vec3 toEye,
                Material mat) {

    // Halfway vector 계산
    vec3 halfway = glm::normalize(lightVec + toEye);

    // Halyway vector를 이용해서 specular albedo 계산
    vec3 specular = mat.specular * pow( glm::max(glm::dot(halfway, normal),0.0f) ,mat.shininess);
    
    // ambient, diffuse, specular 합쳐서 계산
    return mat.ambient + (mat.diffuse + specular) * lightStrength;
}
```
이제 받아온 값을 통해 halfway벡터를 구하고 해당 벡터로 specular를 구하는 공식을 통해 material의 specular값에 곱해준다.

이후 구한 specular와 diffuse를 더하고 표면에 들어오는 빛의 세기만큼 곱한후 ambient를 더해주면 퐁-블린 쉐이딩의 완성이다.
