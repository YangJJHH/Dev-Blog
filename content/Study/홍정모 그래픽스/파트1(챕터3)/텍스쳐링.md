## 텍스쳐 좌표(Texture Coordinate)
각 정점에 컬러값이 아니라 텍스처 이미지의 어떤 좌표를 사용할지 정해주는 것
이미지의 좌표는 UV좌표를 사용한다. 각각 정점에 UV좌표를 지정해줬다면 이제 사각형 내부의 한점의 값은 앞에서 배웠던 무게중심좌표(BaryCentricCoordinate)방법으로 이미지에서 알맞은 픽셀값을 가져와 적용한다.

# Sampling
이미지 여러개의 픽셀값중에서 필요한 픽셀값을 가져와 사용하는 것. 즉 정점에 맞는 UV좌표를 계산하여 이미지로부터 픽셀값을 가져옴
```cpp
 hit.uv = uv0 * w0 + uv1 * w1 + uv2 * (1.0f - w0 - w1); // 텍스춰 좌표
```

위 식은 무게중심좌표계에서 내부 작은삼각형 3개의 넓이 비로 구할 수 있음.

## PointSampling
UV좌표를 구했으면 해당 UV좌표가 실제 이미지좌표에서 어떤값에 해당하는지 이미지 좌표계로 변환해야한다
![[Pasted image 20240811221259.png]]
uv좌표계에서 실제 픽셀 컬러값은 가운데 위치한다고 가정하기 때문에 (0.5,0.5) 만큼의 범위가 늘어나게 되고 따라서 각 좌표계의 범위는 아래와 같다.
- 텍스춰 좌표의 범위 uv [0.0, 1.0] x [0.0, 1.0]
- 이미지 좌표의 범위 xy [-0.5, width - 1 + 0.5] x [-0.5, height - 1 + 0.5]
따라서 uv좌표를 실제 이미지상의 좌표로 좌표계 변환을 한 후 가장 가까운 픽셀의 값을 가져와 적용하는 것이 PointSampling 또는 NearestSampling 이라 한다.

```cpp
vec3 SamplePoint(const vec2 &uv) // Nearest sampling이라고 부르기도 함
		{
			// 텍스춰 좌표의 범위 uv [0.0, 1.0] x [0.0, 1.0]
			// 이미지 좌표의 범위 xy [-0.5, width - 1 + 0.5] x [-0.5, height - 1 + 0.5]
			// 배열 인덱스의 정수 범위 ij [0, width-1] x [0, height - 1]

			// uv좌표계 => 이미지 좌표계 변환
			const float xScale = width;
			const float yScale = height;
			vec2 xy = vec2(width * uv.x - 0.5, height * uv.y - 0.5f);
			int i = glm::round(xy.x);
			int j = glm::round(xy.y);

			return GetClamped(i, j);
			//return GetClamped(0, 0);
		}
```

## LinearSampling
LinearSampling은 PointSampling과 다르게 딱 하나의 픽셀값을 가져오는게 아니라 대응되는 픽셀 주변값들을 가져와 Linear Interpolation하는 기법이다
샘플링할 점 주변 4개의 픽셀 값을 2번  LinearInterPolation한 후 해당 값을 한번 더 InterPolation하는 방법을 Bi-Linear Interpolation이라 한다.
![[Pasted image 20240811225928.png]]
```cpp
vec3 SampleLinear(const vec2 &uv)
		{
			// 텍스춰 좌표의 범위 uv [0.0, 1.0] x [0.0, 1.0]
			// 이미지 좌표의 범위 xy [-0.5, width - 1 + 0.5] x [-0.5, height - 1 + 0.5]
			// std::cout << floor(-0.3f) << " " << int(-0.3f) << std::endl; // -1 0

			// uv좌표계 => 이미지 좌표계 변환
			const float xScale = width;
			const float yScale = height;
			vec2 xy = vec2(xScale * uv.x - 0.5, yScale * uv.y - 0.5f);
			int i = glm::floor(xy.x);
			int j = glm::floor(xy.y);
			const float dx = xy.x - i;
			const float dy = xy.y - j;

			return InterpolateBilinear(dx, dy, GetClamped(i, j), GetClamped(i + 1, j), GetClamped(i, j + 1), GetClamped(i + 1, j + 1));
			//return vec3(1.0f);
		}
```
