삼각형 그리기 기본 원리는 삼각형을 무한한 평명이라 생각하고 눈에서의 레이가 삼각형 내부에서 닿는지 외부에서 닿는지 판단을 한다.
![[Pasted image 20240809211237.png]]

그럼 해당 점을 구하는 식을 유도하는 방법은 아래와 같다
![[Pasted image 20240809212437.png]]
레이와 닿는 점을 p라 하고 레이의 시작점을 o라 하고 레이의 방향을 d라 하면 
![[Pasted image 20240809212532.png]]
해당 식이 성립되고 t를 구하면 정점 p를 구할 수 있다.
p는 삼각형 평면위의 점이기 때문에 v0,v1,v2에서 부터의 p방향의 벡터와 삼각형 노멀벡터n은 항상 수직이라 할 수 있다.

그러면 아래 식이 유도된다.
![[Pasted image 20240809212736.png]]

노멀 벡터n는 v1-v0 와 v2-v0의 외적으로 구할 수 있기 떄문에 n자리에 외적을 이용한 단위벡터 식을 대입하면 t에 대한 방정식이 유도된다.
![[Pasted image 20240809212914.png]]
해당 식을 통해 눈에서부터 레이가 삼각형을 무한히 늘린 평면위에서 충돌하는지를 판단할 수 있다. 즉 충돌 정점 p를 구할 수 있음.

그러면 해당 점 p가 삼각형 안에 있는지를 판단해야 삼각형에 맞게 랜더를 해줄 수 있는데 그 방법은 아래와 같다.

![[Pasted image 20240809215133.png]]
점 p를 기준으로 정점 v0,v1,v2 를 이어 3개의 작은 삼각형으로 나누고 각 삼각형의 노멀이 큰삼각형의 노멀과 방향이 같으면 내부점이라 볼 수 있고,  하나라도 방향이 다르면 외부의 점이라 볼 수 있다.

```cpp
bool IntersectRayTriangle(const vec3 &orig, const vec3 &dir,
								  const vec3 &v0, const vec3 &v1,
								  const vec3 &v2, vec3 &point, vec3 &faceNormal,
								  float &t, float &u, float &v)
		{
			/*
			 * 기본 전략
			 * - 삼각형이 놓여있는 평면과 광선의 교점을 찾고,
			 * - 그 교점이 삼각형 안에 있는지 밖에 있는지를 판단한다.
			 */

			/* 1. 삼각형이 놓여 있는 평면의 수직 벡터 계산 */
			faceNormal = glm::normalize(glm::cross((v1-v0),(v2-v0))); // 외적을 이용한 노멀벡터
			//주의: 삼각형의 넓이가 0일 경우에는 계산할 수 없음

			// 삼각형 뒷면을 그리고 싶지 않은 경우 (Backface culling)
			if (glm::dot(-dir,faceNormal) < 0.0f) return false; // 내적 결과 90도가 넘어가면 음수, 즉 각도가 둔각이면 뒷면에서 충돌

			// 평면과 광선이 수평에 매우 가깝다면 충돌하지 못하는 것으로 판단
			if ( glm::abs(glm::dot(dir,faceNormal)) < 1e-2f) return false; // t 계산시 0으로 나누기 방지

			/* 2. 광선과 평면의 충돌 위치 계산 */
			t = (glm::dot(v0, faceNormal) - glm::dot(orig, faceNormal)) / glm::dot(dir, faceNormal);

			// 광선의 시작점 이전에 충돌한다면 렌더링할 필요 없음
			if (t < 0.0f) return false;

			point = orig + t * dir; // 충돌점

			/* 3. 그 충돌 위치가 삼각형 안에 들어 있는 지 확인 */

			// 작은 삼각형들 3개의 normal 계산
			const vec3 normal0 = glm::cross(v1 - v0, point - v0);
			const vec3 normal1 = glm::cross(v2 - v1, point - v1);
			const vec3 normal2 = glm::cross(v0 - v2, point - v2);
			// 방향만 확인하면 되기 때문에 normalize() 생략 가능
			// 아래에서 cross product의 절대값으로 작은 삼각형들의 넓이 계산

			if (dot(normal0, faceNormal) < 0.0f) return false;
			if (dot(normal1, faceNormal) < 0.0f) return false;
			if (dot(normal2, faceNormal) < 0.0f) return false;

			// Barycentric coordinates 계산
			// 텍스춰링(texturing)에서 사용
			// u = ...
			// v = ...

			return true;
		}
```
