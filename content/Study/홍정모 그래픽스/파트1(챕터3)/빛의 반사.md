이번부터 오브젝트의 reflection,transparency를 사용하게 된다
```cpp
// Material
        vec3 amb = vec3(0.0f);  // Ambient
        vec3 dif = vec3(0.0f);  // Diffuse
        vec3 spec = vec3(0.0f); // Specular
        float alpha = 10.0f;
        float reflection = 0.0; // 반사
        float transparency = 0.0; // 투과
```

반사 구현 전략
레이에 부딪힌 물체가 반사의 성질인 reflection을 가지고 있지 않다면 그냥 퐁쉐이딩을 통한 색결정.
만약 가지고 있다면 해당 지점에서 또 다시 반사광 레이를 발사한다.
![[Pasted image 20240812150205.png]]

원래 물체의 색을 반사,투영도가 적용된 비율만큼 줄여서 적용하고 거기다 반사 +  투영된 색을 더하면 효과를 얻을 수 있다.
![[Pasted image 20240812150652.png]]
```cpp
color += phongColor * (1.0f - hit.obj->reflection - hit.obj->transparency);
```

참고로 반사광은 Specular를 구하는 방법과 동일하게 노멀과 광원벡터로 이용해 구한다
![[Pasted image 20240812151800.png]]

```cpp
const vec3 reflectDir = 2.0f * hit.normal * dot(dirToLight, hit.normal) - dirToLight;
```

반사광 적용 코드
```cpp
if (hit.obj->reflection)
{
	// 여기에 반사 구현
	// 수치 오류 주의
	// 반사광이 반환해준 색을 더할 때의 비율은 hit.obj->reflection

	const vec3 reflectedDirection = glm::normalize(reflectDir);

	// 충돌 지점에 진행방향보다 미세하게 값을 더해서 구해야함, 아니면 해당 물체에 바로 충돌했다 판단할수도 있음
	Ray reflectRay{ hit.point + reflectedDirection * 1e-4f, reflectedDirection };
	color += traceRay(reflectRay, recurseLevel - 1) * hit.obj->reflection;
}
```
