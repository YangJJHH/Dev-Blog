과정
1. 스크린 좌표계 픽셀에서 월드 공간으로 레이를 쏜다(0,1,1) 단위벡터로
2. 해당 레이가 구와 충돌하는지 판단하다. 여기서 구의 방정식과 직선의 방정식의 x값이 같은지 이용, 결국 거리 d를 구하는것.
3. 거리는 3가지 경우가 나오는데
	 1. d >=0
		 d 가 0이면 딱 한 지점에서 충돌
		 d가 0보다 크다면 구를 뚫고 가는 레이, d가 2개가 나오는데 그 중 작은 것을 사용
	2. d <0 
		 충돌하지 않음

Hit IntersectRayCollision(Ray &ray)
        {
            Hit hit = Hit{-1.0f, vec3(0.0f), vec3(0.0f)}; // d가 음수이면 충돌을 안한 것으로 가정

            // 나뷸라 공식
            const float b = 2.0f * glm::dot(ray.dir, ray.start - center);
            const float c = dot(ray.start - center, ray.start - center) - radius * radius;
            const float nabula = b * b / 4.0f - c;
            
            if (nabula >= 0.0f)
            {
                // 나뷸라에서 d를 구하는 공식
                const float d1 = -b / 2.0f + sqrt(nabula);
                const float d2 = -b / 2.0f - sqrt(nabula);

                // 2개가 있다면 거리중 가까운것
                hit.d = glm::min(d1, d2);
                // 레이 시작점부터 레이 방향으로 거리만큼
                hit.point = ray.start + ray.dir * hit.d;
                // 충돌지점의 노멀벡터
                hit.normal = glm::normalize(hit.point - center);  
            }
            /*
             * hit.d = ... // 광선의 시작점으로부터 충돌지점까지의 거리 (float)
             * hit.point = ... // 광선과 구가 충돌한 지점의 위치 (vec3)
             * hit.normal = .. // 충돌 지점에서 구의 단위 법선 벡터(unit normal vector)
             */
            // const float a = glm::dot(ray.dir, ray.dir); // dir이 unit vector라면 a는 1.0f라서 생략 가능

            return hit;
        }
