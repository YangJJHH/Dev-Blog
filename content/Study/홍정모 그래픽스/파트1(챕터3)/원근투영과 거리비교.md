먼 물체는 작게 보이고 가까운 물체가 커보이긴 하는데, 가까이 있는 물체가 가려지는 문제가 있다.
이 부분을 수정해야한다. 
```cpp
Hit FindClosestCollision(Ray& ray)
		{
			Hit closest_hit = Hit{ -1.0, dvec3(0.0), dvec3(0.0) };

			for (int l = 0; l < objects.size(); l++)
			{
				auto hit = objects[l]->CheckRayCollision(ray);

				if (hit.d >= 0.0f)
				{
					hit.obj = objects[l];
					return hit;
				}
			}

			return closest_hit;
		}
```
이런식으로 레이에 첫번째로 닿는 물체가 반환되기 때문에 이부분을 거리가 가장 가까운 물체를 반환하는 형식으로 아래에서 수정

수정코드
```cpp
Hit FindClosestCollision(Ray& ray)
		{
			Hit closest_hit = Hit{ -1.0, dvec3(0.0), dvec3(0.0) };
			float minDistance = 10000.0f; // inf로 가정
			for (int l = 0; l < objects.size(); l++)
			{
				auto hit = objects[l]->CheckRayCollision(ray);

				if (hit.d >= 0.0f)	// 레이에 닿았다면
				{
					if (hit.d < minDistance) // 현재까지 거리가 가장가까운 물체 저장
					{
						minDistance = hit.d;
						closest_hit = hit;
						closest_hit.obj = objects[l];
					}
				}
			}
			return closest_hit;
		}
```
