> ## 원리


우리가 directional,spot,point 세가지 조명효과를 배웠는데 이 세가지를 아무리 조합하더라도 현실같은 복잡한 조명효과를 내기에는 어렵다.

그래서 앞서 배운 환경매핑(반사매핑)을 통하여 조명으로 사용하면 어떨까? 라는 부분에서 시작된다.

![[Pasted image 20241007004101.png]]
우선 환경매핑은 해당 지점에서 큐브맵 방향으로 텍스쳐링을 해서 표현하는데,

아마 텍스쳐링을 여러방향에서 샘플링하면 더 사실적으로 보일것이다. 

하지만 성능상 여러개의 샘플링하는 것보다 **미리 텍스쳐에 다양한 효과들을 적용해놓고 미리 처리된 텍스쳐에서 샘플링 한번만 하는식으로 효율적인 랜더링 방법을 적용해보자**

그래서 다음과 같이 큐브맵에 diffuse버전 specular버전 텍스쳐가 준비되어있다
![[Pasted image 20241007004418.png]]
위쪽의 diffuse텍스쳐는 난반사의 역할을 하기 때문에 상세한 이미지를 부드럽게 전처리한 텍스쳐이고,
아래쪽 specular 텍스쳐는 매끈한 표면을 표현할때 사용하기 때문에 선명한 이미지를 사용한다.

> ## 코드

그럼 코드를 보면서 확인해보자

```cpp
struct CubeMapping {

    std::shared_ptr<Mesh> cubeMesh;

    ComPtr<ID3D11ShaderResourceView> diffuseResView;
    ComPtr<ID3D11ShaderResourceView> specularResView;

    ComPtr<ID3D11VertexShader> vertexShader;
    ComPtr<ID3D11PixelShader> pixelShader;
    ComPtr<ID3D11InputLayout> inputLayout;
};
```
큐브맵 구조체를 보면 두가지 텍스쳐를 사용할거기 때문에 diffuse,specular용 2가지 리소스뷰를 선언해둔다

```cpp
ID3D11ShaderResourceView *views[2] = {m_cubeMapping.diffuseResView.Get(),
                                          m_cubeMapping.specularResView.Get()};
m_context->PSSetShaderResources(0, 2, views);
```
만들어둔 리소스뷰를 마찬가지로 큐브맵픽쉘쉐이더에 전달해준다.



```cpp
// 물체 렌더링할 때 큐브맵도 같이 사용
        ID3D11ShaderResourceView *resViews[3] = {
            mesh->textureResourceView.Get(), m_cubeMapping.diffuseResView.Get(),
            m_cubeMapping.specularResView.Get()};
        m_context->PSSetShaderResources(0, 3, resViews);
```
그 다음 물체를 랜더할떄도 해당 큐브맵 텍스쳐를 광원처럼 사용할 것이기 때문에 물체 쉐이더에도 전달해준다.


BasicPixelShader 코드
```cpp
Texture2D g_texture0 : register(t0);
TextureCube g_diffuseCube : register(t1);
TextureCube g_specularCube : register(t2);
SamplerState g_sampler : register(s0);
```
여기도 원래 모델 텍스쳐 및 큐브맵 텍스쳐를 2개 생성해준다


```cpp
float4 diffuse = g_diffuseCube.Sample(g_sampler, input.normalWorld);
    float4 specular = g_specularCube.Sample(g_sampler, reflect(-toEye,input.normalWorld));
    
    diffuse.xyz *= material.diffuse;
    specular.xyz *= material.specular;
    
    return diffuse + specular;
```
diffuse텍스쳐,specular텍스쳐를 각각 샘플링 한 값에 원래 머테리얼 값을 곱한후 더해줘서 색을 구하고있다.
- diffuse를 구할때 샘플링 하는 방향이 normalWorld인 이유
	 specular랑 다르게 노멀벡터로 구하는 이유는 텍스쳐 자체를 만들때 노멀로 샘플링 할 것으로 간주하고 만드는거라 함.

![[Pasted image 20241007010824.png]]
보면에 큐브맵 천장 텍스쳐 쪽에 조명이 몰려있는데 그래서 구의 표면도 위쪽이 더 밝게 표현되고 있음


specular에 shininess까지 적용한 모습

 specular *= pow( (specular.x + specular.y + specular.z) / 3.0, material.shininess);
