> ## MakeBox

```cpp
// 커다란 박스 초기화
// - 세상이 커다란 박스 안에 갇혀 있는 구조입니다.
// - D3D11_CULL_MODE::D3D11_CULL_NONE 또는 삼각형 뒤집기
// - 예시) std::reverse(myvector.begin(),myvector.end());
MeshData cubeMeshData = GeometryGenerator::MakeBox(20.0f);
std::reverse(cubeMeshData.indices.begin(), cubeMeshData.indices.end());

AppBase::CreateVertexBuffer(cubeMeshData.vertices,
                                m_cubeMapping.cubeMesh->vertexBuffer);
m_cubeMapping.cubeMesh->m_indexCount = UINT(cubeMeshData.indices.size());
AppBase::CreateIndexBuffer(cubeMeshData.indices,
                               m_cubeMapping.cubeMesh->indexBuffer);
```
20 크기의 커다란 박스를 만들어준다.
D3D11_CULL_NONE 을 해야 뒷면도 그려준다. 박스 내부에서 봐야하기 때문에
인덱스를 reverse 하는 걸 볼수있는데 우리는 박스내부가 보이는 상태이기 때문에 반시계방향으로 삼각형을 그려야 잘 보인다.

> ## VertexShader

```cpp
#include "Common.hlsli"

cbuffer BasicVertexConstantBuffer : register(b0)
{
    matrix model;
    matrix invTranspose;
    matrix view;
    matrix projection;
};

PixelShaderInput main(VertexShaderInput input)
{
    // 불필요한 멤버들도 VertexShaderInput을 통일시켰기 때문에 채워줘야 합니다.
    
    PixelShaderInput output;
    float4 pos = float4(input.posModel, 1.0f);

    pos = mul(pos, model); // Identity

    output.posWorld = pos.xyz;
    
    float4 normal = float4(input.normalModel, 0.0f);
    output.normalWorld = mul(normal, invTranspose).xyz;
    output.normalWorld = normalize(output.normalWorld);

    pos = mul(pos, view);
    
    pos = mul(pos, projection);
    output.posProj = pos;

    output.texcoord = input.texcoord;
    output.color = float3(1.0, 1.0, 0.0);

    return output;
}

```

model 행렬은 Identity 행렬이 들어온다
그 이유는 오브젝트들이 움직이거나 회전해도 세상은 배경이 같이 움직이면 안되기 떄문.
대신 view,proj 행렬은 들어가야함

노멀,texcoord,color은 사실 필요없는데 다른 쉐이더와 맞춰주기 위해

> ## PixelShader

```cpp
TextureCube g_textureCube0 : register(t0);
SamplerState g_sampler : register(s0);

float4 main(PixelShaderInput input) : SV_TARGET
{
    // 주의: 텍스춰 좌표가 float3 입니다.
    return g_textureCube0.Sample(g_sampler, input.posWorld.xyz);
}
```
아주 간단하다.
우선 Texture가 아니라 TextureCube이다
그 다음 텍스쳐 좌표가 2차원이 아니라 float3이다.
왜일까??
일단 일반적인 Texture2D가 아니라 TextureCube이라는 큐브맵 전용 텍스쳐라는 점에서 2차원 좌표를 사용할 수 없다.(GPU로 텍스쳐 한장을 6번이 아니라 6장이 모두 포함된 텍스쳐를 보냄)
![[Pasted image 20241006011433.png]]
6개의 면을 다 갖고 있는 텍스쳐 이므로, 우리가 큐브 중앙에 있다고 가정했을때 현재 계산되는 픽셀이 큐브맵 원점으로부터 어떤 방향에 있는 픽셀인지 안다면 텍스쳐를 샘플링 해 올 수 있다. 따라서 월드상 좌표를 가져와야 한다.
