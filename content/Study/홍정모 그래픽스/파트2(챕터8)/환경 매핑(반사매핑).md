우선 2가지 방법이 있는데
1. 이동이나 뷰의 회전과는 관계없이 매핑되어있는 모습
2. 완전 반사로 구 자체가 거울이라 생각하고 뷰 회전까지 반영되는 모습

> ## 첫번째 방법


첫번째 방법의 원리는 다음과 같다
구의 표면의 노멀 방향으로 큐브맵의 텍스쳐를 샘플링 해오는 것

> ## 코드


PixelShader 코드를 보자면
```cpp
Texture2D g_texture0 : register(t0);
// TODO:
TextureCube g_textureCube1 : register(t1);
SamplerState g_sampler : register(s0);
```
픽쉘세이더에서 큐브맵의 텍스쳐를 샘플링 해와야하기 때문에  TextureCube g_textureCube1를 선언해준다.

```cpp
return g_textureCube1.Sample(g_sampler, input.normalWorld);
```
그 후 색을 결정하는 코드를 기존 쉐이딩 코드가 아니라 현재 픽셀의 노멀방향으로 큐브맵의 해당되는 텍스쳐를 샘플링해와 랜더링을 한다.

cpp코드에선 큐브텍스쳐 하나를 더 전달해줘야 하므로 리소스뷰를 추가해서 전달
```cpp
 // TODO: 물체 렌더링할 때 큐브맵도 같이 사용
ID3D11ShaderResourceView *resViews[2] = {
	mesh->textureResourceView.Get(),
	m_cubeMapping.cubemapResourceView.Get()};
m_context->PSSetShaderResources(0, 2, resViews);
```

> ## 두번째 방법

레이트레이싱에서 구현했던 완전반사광과 동일하게 구현한다고 생각하면 된다.
근데 여기서 빛의 방향이 아니라 눈의 방향으로 적용해서.
직접 반사광식을 구현할 필요는 없고 directx에서 제공되는 reflect함수를 사용하면 된다.
```cpp
// reflect(광선이 들어오는 방향, 노멀 벡터)
    // https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-reflect
    return g_textureCube1.Sample(g_sampler, reflect(-toEye, input.normalWorld));
```
주의할점은 우리가 구한 toEye 벡터는 현재픽셀에서 눈까지의 방향벡터인데
reflect함수인자가 (광선이 들어오는 방향, 노멀 벡터) 이기 때문에 -toEye를 넣어준다
