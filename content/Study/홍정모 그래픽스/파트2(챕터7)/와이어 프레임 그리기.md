RasterizerState를 바꾸어 그릴 수 있다.

우선 WireFrame용 state를 하나 더 생성하고
```cpp
 // TODO: RasterizerState를 2개 만들기
    ComPtr<ID3D11RasterizerState> m_solidRasterizerSate;
    ComPtr<ID3D11RasterizerState> m_wireRasterizerSate;
```

기존 solidState 생성과 동일한 DESC에서 FillMode옵션만 D3D11_FILL_WIREFRAME로 바꾸어
device를 통해 생성한다.
```cpp
 // Create a rasterizer state , Solid
    D3D11_RASTERIZER_DESC rastDesc;
    ZeroMemory(&rastDesc, sizeof(D3D11_RASTERIZER_DESC)); // Need this
    rastDesc.FillMode = D3D11_FILL_MODE::D3D11_FILL_SOLID;
    // rastDesc.FillMode = D3D11_FILL_MODE::D3D11_FILL_WIREFRAME;
    rastDesc.CullMode = D3D11_CULL_MODE::D3D11_CULL_NONE;
    rastDesc.FrontCounterClockwise = false;
    rastDesc.DepthClipEnable = true; // <- zNear, zFar 확인에 필요
    m_device->CreateRasterizerState(&rastDesc,
                                    m_solidRasterizerSate.GetAddressOf());

    // TODO: WireFrame
    rastDesc.FillMode = D3D11_FILL_MODE::D3D11_FILL_WIREFRAME;
    m_device->CreateRasterizerState(&rastDesc, m_wireRasterizerSate.GetAddressOf());
```

이후 GUI를 통해 얻은 체크 옵션을 통해 Render시 어떤 State를 사용하여 랜더할지
RSSetState를 호출해준다.

 // TODO:
