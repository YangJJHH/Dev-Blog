다음과 같이 ob,mtl파일이 나온다
- obj
	vertex,index,normal정보
- mtl(material)
	texture,color

obj파일을 텍스트 파일로 열어보면 다음과 같이 
v , vn, f 과 같이 vertex,vertexnormal,index 값이 나열되게 되는데 이러한 값을 파일 형식에 맞추어 읽어들이는게 모델링을 로드하는 방법이다.
![[Pasted image 20241005222602.png]]


이번에 우리는 이 3D모델을 로드하는함수를 직접 짜는것은 아니고 정모형이 만들어준 해당 함수로 읽어들여본다.
참고로 해당 함수 사용하려면 assimp를 설치해줘야함
```cpp
 auto meshes =
        GeometryGenerator::ReadFromFile("D:\\Blender\\", "untitled.obj");
```

모델 정보를 로드했다면 mesh마다 Vertexbuffer와 IndexBuffer에 해당 데이터를 저장해주고
텍스쳐를 사용한다면 텍스쳐 파일이름 토대로 Texture 및textureResourceView 또한 생성해준다.
복잡한 모델 같은 경우는 로드하면 mesh가 여러개 포함되어있다.
```cpp
   for (const auto &meshData : meshes) {
        auto newMesh = std::make_shared<Mesh>();
        AppBase::CreateVertexBuffer(meshData.vertices, newMesh->vertexBuffer);
        newMesh->m_indexCount = UINT(meshData.indices.size());
        AppBase::CreateIndexBuffer(meshData.indices, newMesh->indexBuffer);

        if (!meshData.textureFilename.empty()) {

            cout << meshData.textureFilename << endl;
            AppBase::CreateTexture(meshData.textureFilename, newMesh->texture,
                                   newMesh->textureResourceView);
        }

        newMesh->vertexConstantBuffer = vertexConstantBuffer;
        newMesh->pixelConstantBuffer = pixelConstantBuffer;

        this->m_meshes.push_back(newMesh);
    }
```
