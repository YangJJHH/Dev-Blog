Grid를 만드는 함수는 그리드의 전체 width,height, 가로로 몇칸, 세로로 몇칸 자를지 인자로 넘겨준다.


여기서는 left-bottom 을 기준으로 그리드를 쌓아올리는 방식이다
```cpp
MeshData GeometryGenerator::MakeGrid(const float width, const float height,
                                     const int numSlices, const int numStacks) {

    // 안내: 실린더와 구 만들기 이해를 돕기 위해 후속 녹화한 강의입니다.

    // x-y 평면 (z = 0) 위에 격자 구조로 평면 만들기
    // 뒤에서 복잡한 지형으로 확장

    // 1단계: numStacks = 1 이고 numSlices만 고려해서 구현
    // 2단계: 2차원 바둑판 구조

    const float dx = width / numSlices;
    const float dy = height / numStacks;

    MeshData meshData;

    vector<Vertex> &vertices = meshData.vertices;
    vector<uint16_t> &indices = meshData.indices;


    
    // 세로 칸만큼
    for (int j = 0; j <=numStacks; j++) {
        Vector3 stackStartPoint = Vector3(-0.5f * width, -0.5f * height + j * dy, 0.0f);
        // 가로 칸 만큼
        for (int i = 0; i <= numSlices; i++) {
            Vertex v;

            // x-y 평면에서 시작점을 x 방향으로 이동
            v.position = Vector3::Transform(
                stackStartPoint,
                Matrix::CreateTranslation(Vector3(dx * float(i), 0.0f, 0.0f)));

            // 시점을 향하는 방향
            v.normal = Vector3(0.0f, 0.0f, -1.0f);

            v.texcoord = Vector2(float(i) / numSlices, 1 - float(j) / numStacks);

            vertices.push_back(v);
        }
    }

    // 인덱스 추가
    for (int j = 0; j < numStacks; j++) {
        for (int i = 0; i < numSlices; i++) {

            int startIdx = j * (numSlices+1);
            // 첫번째 삼각형
            indices.push_back(i + startIdx);
            indices.push_back(i + startIdx  + 1);
            indices.push_back(i + startIdx  + numSlices + 1);
            // 두 번째 삼각형
            indices.push_back(i + startIdx + numSlices + 1);
            indices.push_back(i + startIdx + numSlices + 2);
            indices.push_back(i + startIdx + 1);
        }

    }
    
    return meshData;
}
```
