## **함수 오버로딩의 이해 (Function Overloading)**

C언어에서는 다음과 같이 동일한 이름의 함수가 정의되는 것을 허용하지 않음 => 컴파일 오류 발생

```cpp
int MyFunc(int num)
{
	num++;
	return num;
}

int MyFunc(int a, int b)
{
	return a + b;
}
```

하지만 C++은 이를 허용하고 있다. **함수 호출 시 전달되는 인자를 통해서 호출고하자 하는 함수의 구분이 가능하기 때문.**

이러한 형태를 가리켜 함수 오버로딩( Function Overloading )이라 한다.

> 그렇다면 왜 C++은 이를 허용하고 C는 허용하지 않은 이유는 무엇일까?

**이는 호출할 함수를 찾는 방법이 서로 다르기 때문.**

> **함수를 찾을때 필요한 정보**

> **C++ : 함수의 이름, 매개변수 선언**

> **C : 함수의 이름**

때문에 C언어에서는 함수의 오버로딩이 불가능하며, 이를 문법적으로도 허용하지 않음

## **함수 오버로딩의 예**

> **매개변수의 선언이 달라야한다 ( 자료형 또는 갯수)**

```cpp
// 아래는 매개변수 자료형이 서로 다름
int MyFunc(int n) { ... }
int MyFunc(char n) { ... }
```

```cpp
// 아래는 매개변수 갯수가 서로 다름
int MyFunc(int a, int b) { ... }
int MyFunc(int a) { ... }
```

위는 올바른 예시

> **잘못된 예**

```cpp
// 아래는 반환형이 서로 다름
int MyFunc(int n) { ... }
void MyFunc(int n) { ... }
```
