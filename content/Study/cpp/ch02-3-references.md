## Reference의 이해

변수의 정의는 다음과 같다

> 변수는 할당된 메모리 공간에 붙여진 이름이다. 그리고 그 이름을 통해서 해당 메모리 공간에 접근이 가능하다.

그렇다면 할당된 하나의 메모리 공간에 둘 이상의 이름을 부여할 수는 없을까??

예를 들기 위해 변수를 하나 선언해보자

```cpp
int num1 = 2010;
```

![[6-1.png]]

변수 선언을 통해서 2010으로 초기화 된 메모리 공간게 num1이라는 이름이 붙게된다.

그런데 이상황에서 다음의 문장을 실행하면, num1이라는 이름이 붙어있는 메모리 공간에 num2라는 이름이 하나 더 붙게된다.

```cpp
int &num2 = num1;
```

![[6-2.png]]

보통 &연산자는 변수의 주소 값을 반환하는 연사자로 사용되지만, 위처럼 다른 의미로도 사용된다.

- 이미 선언된 변수의 앞에 사용되면 주소값 반환
- 새로 선언되는 변수 앞에 사용되면 참조자의 선언을 뜻함

```cpp
int* ptr = &num1; // 변수 num1의 주소 값을 반환해서 ptr에 저장!
int& num2 = num1; // num1에 대한 참조자 num2 선언!
```

> 그럼 참조자도 변수인가?

사실상 변수로 봐도 무리는 없다, 그 기능과 연산결과가 변수와 동일하다.

**하지만 C++에서는 참조와 변수를 구분해서 이야기한다.**

**참조는 자신이 참조하는 변수를 대신할 수 있는 또 하나의 이름**

## **참조자의 수에는 제한이 없으며, 참조자를 대상으로도 참조자를 선언할 수 있다.**

**참조자의 수에는 제한이 없다. 즉 여러개의 참조자를 선언하는것도 가능하다.**

```cpp
int num1 = 2010;
int& num2 = num1;
int& num3 = num1;
int& num4 = num1;
```

![[6-3.png]]

메모리 공간에 num1,num2,num3,num4 라는 이름을 붙인 의미.

그리고 참조자를 대상으로 참조자를 선언하는 것도 가능.

```cpp
int num1 = 2010;
int& num2 = num1;
int& num3 = num2;
int& num4 = num3;
```

즉 위의 문장을 실행해도 위 그림과 동일한 결과가 만들어진다.

## 참조자의 선언 가능 범위

참조자는 변수에 대해서만 선언이 가능하고, 선언됨과 동시에 누군가를 참조해야만 한다.

즉 다음의 선언은 유효하지 않다

```cpp
int& ref = 20; 		// ( x )
```

참조자는 변수의 별칭을 붙이는것이기에 상수를 대상으로 선언할 수 없다.

```cpp
int& ref;			// ( x )
```

다음과 같이 미리 선언했다가 후에 참조하는것도 불가능하며, 참조의 대상을 바꾸는 것도 불가능하다.

```cpp
int& ref = NULL; 	// ( x )
```

물론 참조자를 선언하면서 NULL로 초기화하는 것도 불가능하다.

**참조자는 무조건 선언과 동시에 변수를 참조하도록 해야한다.**
