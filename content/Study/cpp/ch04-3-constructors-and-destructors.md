## 생성자의 이해

```cpp
class SimpleClass
{
private:
	int num;
public:
	SimpleClass(int n) // 생성자
	{
		num = n;
	}
};
```

위의 클래스 정의에서 다음의 형태를 띠는 함수가 있다.

- 클래스의 이름과 함수의 이름이 동일하다
- 반환형이 선언되지 않으며, 실제로 반환하지 않는다

이러한 유형의 함수를 가리켜 **생성자**라 한다. 다음과 같은 특징을 갖는다.

> 객체 생성시 딱 한번 호출된다.

위와 같이 생성자가 정의된 클래스의 객체를 생성할땐 생성자의 인자정보를 추가해야한다.

```cpp
SimpleClass sc(20); // 전역,지역 및 매개변수의 형태
SimpleClass* ptr = new SimpleClass(20); // 동적할당 형태
```

- 생성자도 함수의 일종이니 오버로딩이 가능하다.
- 생성자도 함수의 일종이니 매개변수에 디폴트값을 설정 할 수 있다.

## 멤버 이니셜라이저를 이용한 멤버 초기화

```cpp
public:
	Point(const int &_x, const int &_y) // 생성자
	{
		x = _x;
		y = _y;
	}
};

class Rectangle
{
private:
	Point upLeft;
	Point lowRight;

public:
	Rectangle(int x1, int y1, int x2, int y2)
		:upLeft(x1, y1), lowRight(x2, y2) // 멤버 이니셜라이저
	{
		// empty
	}
};
```

다음은 좌표 네개를 받아 Point객체 2개를 갖는 Rectangle객체를 초기화 하는 과정이다.

이 중에서 다음의 내용이 멤버 이니셜라이저다

> :upLeft(x1, y1), lowRight(x2, y2) // 멤버 이니셜라이저

그리고 이것이 의미하는 바는 다음과 같다

- 객체 upLeft의 생성과정에서 x1,y2을 인자로 전달받는 생성자를 호출하라
- 객체 lowRight의 생성과정에서 x2,y2을 인자로 전달받는 생성자를 호출하라

이렇듯 멤버 이니셜라이저는 멤버변수로 선언된 객체의 생성자 호출에 활용된다.

그럼 객체의 생성과정을 다음과 같이 정리할 수 있다.

- 1단계 : 메모리 공간의 할당
- 2단계 : 이니셜라이저를 이용한 멤버변수의 초기화
- 3단계 : 생성자의 몸체 부분실행

C++의 모든 객체는 위의 세가지 과정을 순서대로 거쳐 생성된다.

> 그럼 생성자도 이니셜라이저도 없으면 메모리 공간 할당만으로 객체가 생성될까??

아니다, 이니셜라이저 같은 경우는 선택을 할 수 있지만 생성자는 객체 생성에 필수이다!

만약 생성자를 정의하지 않는 경우라도 ***디폴트 생성자***자동으로 삽입되어 호출된다.

## 멤버 이니셜라이저를 이용한 변수 및 const 변수 초기화

이니셜라이저를 통해 객체뿐 아니라 일반 변수에도 초기화 가능하다.

```cpp
class Sample
{
private:
	int num1;
	int num2;
public:
	Sample(int n1, int n2) : num1(n1)
	{
		num2 = n2;
	}
};
```

다음과 같이 num1을 n1의 값으로 초기화 시킬 수 있다.

프로그래머는 생성자의 몸체에서 초기화하는법, 이니셜라이저를 통해 초기화 하는법 두가지를 선택 가능하다.

그러나 일반적으로 이니셜라이저를 선호하는 편이 좋다.

그 이유는 아래와 같은 이점이 있기 때문이다

- 초기화의 대상을 명확히 인식할 수 있다
- 성능에 약간 이점이 있다
- 선언과 동시에 초기화가 이뤄지기 때문에 const변수를 멤버에 선언하여 초기화 시킬수 있다

비유를 하자면

> 생성자의 몸체를 통해 초기화 하는과정
> 
> int num1;
> 
> num1 = n1;
> 
> 이니셜라이저를 통한 초기화
> 
> int num1 = n1;

> 즉 이니셜라이저를 이용하면 선언과 동시에 초기화가 이뤄지는 형태로 바이너리 코드가 생생된다.

const 변수는 선언과 동시에 초기화 해야 하기 때문에 이니셜라이저를 통해 멤버변수에 사용가능하다.

## 이니셜라이저의 이러한 특징은 멤버변수로 참조자도 선언할 수 있다

const 변수와 마찬가지로 참조자도 선언과 동시에 초기화가 이뤄져야 한다. 따라서 이니셜라이저를 이용하면 참조자도 멤버변수로 선언할 수 있다.

## 소멸자의 이해와 활용

객체생성시 반드시 호출되는 것이 생성자라면 객체 소멸시 반드시 호출되는 것은 소멸자이다. 소멸자는 다음의 형태를 갖는다

- 클래스의 이름앞에 '~' 가 붙은 형태의 이름을 갖는다.
- 반환형이 선언되지 않으며, 실제로 반환하지 않는다
- 매개변수는 void형으로 선언되어야 하기 때문에 오버로딩도, 디폴트값 설정도 불가능하다.

소멸자 역시 직접 정의하지 않아도 디폴트 소멸자가 삽입되어 객체 소멸시 호출된다.

이러한 소멸자는 보통 객체 내부에서 사용한 리소스 해제에 사용된다.
