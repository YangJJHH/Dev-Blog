## 매크로 함수의 장점

우선 인라인 함수를 배우기에 앞서 인라인 함수가 나온 배경부터 알아보자.

C언어에서의 매크로 함수의 장점은 다음과 같다

> 일반적인 함수에 비해서 실행속도의 이점이 있다.

반면 단점은 다음과 같다

> 정의하기가 어렵다. 복잡한 함수를 매크로의 형태로 정의하는데 한계가 있다.

따라서 위와 같은 장점은 유지를 하되 단점은 제거된 함수가 C++의 인라인 함수이다.

## 인라인 함수 정의

다음은 인라인 함수 정의방법이다.

```cpp
#pragma once
#include <iostream>

inline int SQUARE(int x)
{
	return x * x;
}

int main(void)
{
	std::cout << SQUARE(5) << std::endl;
	return 0;
}
```

- 키워드 inline의 선언을 통해서 함수 SQUARE는 인라인 함수가 되었다.
- SQUARE함수를 호출할때 이는 인라인 함수이므로 몸체부분이 호출부분을 대체하게된다.

> 참고로 매크로를 이용한 함수의 인라인화는 전처리기에 의해서 처리되었지만, 키워드 inline을 이용한 함수의 인라인화는 컴파일러에 의해서 처리가된다.

따라서 컴파일러는 함수의 인라인화가 오히려 성능에 해가 된다고 판단할 경우, 이 키워드를 무시해버리기도 한다. 또한 컴파일러는 필요한 경우 일부 함수를 임의로 처리하기도 한다.

## 매크로 함수에는 있지만, 인라인 함수에는 없는 장점

사실 위의 인라인 함수는 매크로 함수의 장점을 완전히 대체하지 못했다.

매크로 함수의 경우

```cpp
#define SQUARE(x) ((x)*(x)) // 자료형에 자유로움
```

자료형에 의존적이지 않지만 인라인함수는 int형 기반으로 정의된 함수이기 떄문에 다른 자료형에 대해서 데이터 손실이 발생한다. 물론 오버로딩을 통해 여러개의 자료형 버전을 만들어도 되지만 이는 매크르 함수의 장점과는 멀어지게된다

그러나 C++의 템플릿이라는 것을 이용하면 매크로함수와 마찬가지로 자료형에 의존적이지 않은 함수로 사용할수있다.

아직 템플릿을 공부하기 전이니 예시만 확인해보겠다.

```cpp
template <typename T>
inline T SQUARE(T x)
{
	return x * x;
}
```
