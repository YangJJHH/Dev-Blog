복사 생성자가 호출되는 시점은 크게 세가지로 구분할 수 있다.

- case 1 : 기존에 생성된 객체를 이용해서 새로운 객체를 초기화 하는 경우
- case 2 : Call-by-Value 방식의 함수호출 과정에서 객체를 인자로 전달하는 경우
- case 3 : 객체를 반환하되, 참조형으로 반환하지 않은 경우

이들은 모두 다음의 공통점을 가진다.

> 객체를 새로 생성해야 한다. 단 생성과 동시에 동일한 자료형의 객체로 초기화 해야한다.

복사 생성자의 호출시기를 논하기에 앞서, 먼저 메모리 공간이 할당과 동시에 초기화되는 상황을 보자

```cpp
int num1 = num2;
```

이는 num1의 메모리 공간을 할당함과 동시에 num2의 저장된 값으로 초기화가 이루어진다.

다음을 보자

```cpp
int Sample(int n)
{
	...
}
int main(void)
{
	int num = 2;
    Sample s(num); // 호출되는 순간 매개변수 n이 할당과 동시에 초기화!
	return 0;
}
```

위의 코드에선 매개변수n이 할당과 동시에 변수 num에 저장된 값으로 초기화된다.

이렇듯 매개변수도 함수가 호출되는 순간에 할당되므로, 이 상황에도 할당과 초기화가 동시에 일어나는 상황이다.

마지막 케이스를 보자

```cpp
int SampleFunc(int n)
{
	...
    returm n;
}
int main(void)
{
	int num = 10;
    cout << SampleFunc(num) <<endl;
	return 0;
}
```

위의 코드를 보면 다음과 같이 의아해 할 수 있다.

- 정수를 반환하는데, 그 과정에서 메모리 공간이 할당된다고??
- 잘못된 설명 아닌가? 반환된 값을 새로운 변수에 저정하는것도 아니잖아!

하지만 반환된 값을 별도의 변수에 저장하는것과 별개로, 값을 반환하면 반환된 값은 별도의 메모리 공간이 할당되어 저장된다. 반환되는 값을 메모리 공간 어딘가에 저장하지 않는다면 cout에 의한 출력이 가능하겠는가??

## 임시객체

위의 내용을 설명하기 위해 임시객체라는 개념이 등장한다.

```cpp
class Temporary
{
private:
	int num;
public:
	Temporary(int n) : num(n)
	{
		cout << "Create Obj" << endl;
	}
	~Temporary()
	{
		cout << "Delete Obj" << endl;
	}
	void Show()
	{
		cout << "Show Obj" << endl;
	}
};

int main(void)
{
	Temporary(100).Show();
	const Temporary& ref = Temporary(10);
	return 0;
}
```

클래스 외부에서 객체의 멤버함수를 호출하기 위해 필요한 것은 다음 세가지중 하나이다.

- 객체에 붙여진 이름
- 객체의 참조 값
- 객체의 주소 값

그런데 임시객체가 생성된 위치에는 임시객체의 참조값이 반환된다.

```cpp
Temporary(100).Show();
```

즉 위의 문장의 경우

> (임시객체 참조값).Show();

위와 같은 형태가 된다. 그래서 멤버함수 호출이 가능한 것이다.

또한 이렇듯 참조값이 반환되기 때문에 다음과 같은 문장의 구성도 가능하다.

```cpp
const Temporary& ref = Temporary(10);
```

실제로는 임시객체가 통째로 반횐는것이 아니라, 임시객체는 메모리에 저장되고 그 객체의 참조값이 반환되는 것이다.

임시객체는 실제로 이름이 없는 객체이기 때문에 const 참조자를 통해 상수참조와 같은 개념으로 받아낸다.

**임시객체를 const가 없이 참조자만으로 초기화하는경우 컴파일 에러 발생**

임시객체는 다음과 같은 특징이 있다.

- 임시객체는 다음 행으로 넘어가면 바로 소멸되어 버린다.
- 참조자에 참조되는 임시객체는 바로 소멸되지 않는다.

한가지 더 알아두면 좋은점은

```cpp
Temporary temp = Temporary(10);
```

위와 같은 코드에서 temp라는 객체를 생성해 임시객체를 가지고 대입연산을 하는 것처럼 보이지만

사실은 임시객체에 temp라는 이름을 할당하는 것으로 객체를 추가 생성하진 않는다.
