## 클래스와 구조체의 유일한 차이점

앞서만든 구조체 예제에서 struct 키워드를 아래와 같이 class로 바꿔보자.

```cpp
class Car
{
	char szID[256];
    int speed;
    int fuel;
};

int main(void)
{
	Car basicCar = {"run",90,100};  (x)
	return 0;
}
```

우선 문제가 되는 부분은 구조체 초기화 부분이다.

이유는 클래스내에 선언된 함수가 아닌, 다른 영역에서 초기화하려 했기 때문이다.

클래스는 기본적으로 클래스 내에 선언된 변수는 별도의 지시가 없으면 클래스 내에 선언된 함수에서만 접근가능하다.

따라서 별도의 지시를 해줘야하는데 이러한 **변수 및 함수의 접근 허용범위를 별도로 선언해야 하는 부분이 클래스와 구조체의 유일한 차이점이다.**

## **접근제어 지시자(접근제어 레이블)**

C++의 접근제어 지시자는 다음과 같이 총 세가지가 존재한다.

- public : 어디서든 접근허용
- protected : 상속관계에 놓여있을때, 유도클래스에서 접근허용
- private : 클래스 내(클래스 내에 정의된 함수) 에서만 접근 허용

**참고로 class에서는 멤버에 대한 디폴트 접근제어가 private이고, 구조체에서는 public 이다.**

**구조체도 접근제어 지시자의 선언이 가능하고 그 의미도 동일하다. 다만 접근제어 지시자를 선언하지 않았을 경우 디폴트로 public으로 선언할 뿐이다.**

올바른 클래스 선언 및 정의

```cpp
class Car
{
	char szID[256];
    int speed;
    int fuel;
};

int main(void)
{
	Car basicCar;
	return 0;
}
```

id,speed,fuel 과 같은 변수는 클래스의 멤버라는 의미로 멤버변수라 칭한다.

여기서 basicCar는 클래스 변수라 부르는것이 아니라 이제부터 객체라 칭한다.

초기화는 따로 Init함수를 만들거나 후에 나오는 생성자에서 진행한다.
