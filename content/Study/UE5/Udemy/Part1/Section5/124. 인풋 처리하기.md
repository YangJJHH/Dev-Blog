
## Deprecated System
이제 Pawn Possess까지 했지만 아직 인풋 작업을 안해서 움직일 수 없다
이번에 인풋처리를 해보자
![[Pasted image 20260712172543.png]]

우리는 현재 이렇게 action,axis mapping을 설정해 두었고 아직 여기에 바인딩을 안한 상태이다.

이것을 바인딩 할 수 있는 함수는 Pawn 클래스에 자동으로 가상함수로 추가된다.
우리의 BasePawn에 생성되어 있지만 BasePawn은 인풋처리가 필요없기 때문에 이 함수를 제거하고 Tank로 가져와 오버라이딩 해보자.
```cpp
// Called to bind functionality to input
virtual void SetupPlayerInputComponent(class UInputComponent* PlayerInputComponent) override;
```

<font color="#9bbb59">참고로 위 함수는 우리가 따로 호출하는게 아니라, Pawn에 Possess할떄 언리얼 엔진이 자동으로 호출해주는 함수이다</font>

그럼 아래처럼 Tank클래스에서 오버라이딩 하고
```cpp
void ATank::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
	Super::SetupPlayerInputComponent(PlayerInputComponent);
	PlayerInputComponent->BindAxis(TEXT("MoveForward"), this, &ATank::Move);
}
```

BindAxis 인자는 각각
1.  Mapping 세팅에서 설정한 이름
2. 바인딩 할 함수가 있는 객체 포인터
3. 바인딩할 함수 주소
