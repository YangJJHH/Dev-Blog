# BlueprintImplementableEvent

이번에 BlueprintImplementableEvent를 통해 구현해볼거다
BlueprintImplementableEvent는 C++에서는 호출만 가능하고 해당 함수를 호출하먄 블루프린트에서 해당 Event가 발생해 관련 로직을 호출하는 구조이다.

``` C
	UFUNCTION(BlueprintImplementableEvent)
	void StartGame();
```
다음과 같이 선언할 수 있고.
이 함수는 C++에서 구현 못한다.

그럼 이제 블루프린트에서 확인 가능
