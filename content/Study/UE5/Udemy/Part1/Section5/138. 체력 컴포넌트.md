# 그럼 어디서 바인딩할까?
나는 처음에 당연히 BasePawn에서 컴포넌트를 생성해서 바로 바인딩 할 줄 알았는데.
강의에선 헬스컴포넌트 자체에서 GetOwner로 pawn을 가져와 컴포넌트 내부에서 바인딩 해주고 있다.

의아해서 찾아보니 설계 구조상 책임을 컴포넌트가 갖게 하는게 맞다고 한다.
왜냐하면 "Owner의 데미지 이벤트를 듣는 것"도 HealthComponent의 책임이고
Pawn이 컴포넌트 내부 동작까지 알아야 필요는 없기 때문에.

그래서 다음과 같이 연결한다.
바인딩을 해주는 마찬가지로 AddDynamic() => 근데 이게 함수가 아니라 매크로로 되어있음 다른 함수 래핑중

```c
void UHealthComponent::BeginPlay()
{
	Super::BeginPlay();
	Health = MaxHealth;
	// ...
	GetOwner()->OnTakeAnyDamage.AddDynamic(this, &UHealthComponent::DamageTaken);
}
```
