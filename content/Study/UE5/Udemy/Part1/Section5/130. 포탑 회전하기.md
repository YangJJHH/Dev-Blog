더 쉬운 방법이 있었다
FVector::Rotation() 함수는
한 벡터의 방향이 월드기준으로 어떠한 회전값을 갖는지 (pitch,yaw,roll) 형태로 Rotator로 전달해주는데.

아래처럼 A를 원점이라 생각하고 목표인 마우스 포인터가 hit 위치가 원점으로부터 어떠한 회전을 갖는지를 구할수있다.
![[Pasted image 20260714214344.png]]

이제 월드상 마우스 hit 위치가 몇도만큼 회전 되어있는지 알기 때문에
이후 SetWorldRotation()라는 함수를 통해 똑같이 world상 yaw값을 해당 회전값으로 설정해주면 된다.

```cpp
void ABasePawn::RotateTurret(FVector LookAtTarget)
{
	FVector dir = LookAtTarget - TurretMesh->GetComponentLocation();
	FRotator LookAtRotation = FRotator(0.f, dir.Rotation().Yaw, 0.f);
	TurretMesh->SetWorldRotation(LookAtRotation);
}
```
위 함수는 BasePawn 생성해 Tower에서도 쓸수있도록하자


이제 회전하는거 까지는 구현!
근데 이걸 Tick함수에서 그냥 호출하면 완전 휙휙 돌아감
특히 마우스가 탱크중심을 지날떄 그냥 휙 돌아감

그래서 회전값을 그냥 설정하는것이 아니라 보간을 해야함
```cpp
FMath::RInterpTo(TurretMesh->GetComponentRotation(), LookAtRotation, UGameplayStatics::GetWorldDeltaSeconds(this), 5.0f)
```

해당 함수를 사용해 회전값을 보간할수있다.
마지막 5.0f에 해당하는 인자의 값이 클수록 빠르게 보간된다

이렇게 되면 좀더 부드러운 회전을 갖을수있다.

참고로 RInterpTo 이함수는 목표값에 다가갈수록 느려진다.
즉 목표에 도달할수록 천천히 보간됨

RInterpConstantTo는 항상 일정하게 보간
마지막 인수가 보간 속도라 생각하면된다
