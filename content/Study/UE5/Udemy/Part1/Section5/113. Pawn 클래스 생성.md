
우선 Pawn이 어떤 위치에 있는지 보자

```
UObject
├── AActor
│     └── APawn
│           └── ACharacter
│
└── UActorComponent
      ├── USceneComponent
      │      └── UPrimitiveComponent
      │              ├── UStaticMeshComponent
      │              ├── USkeletalMeshComponent
      │              ├── UCapsuleComponent
      │              └── ...
      └── UMovementComponent
```

상속 관계는 다음과 같다

## 즉 AActor는 그냥 컨테이너 껍데기이다.
그 자체로 위치나 물리를 갖고 있지 않다.
하지만 Actor는 루트 컴포넌트로 USceneComponent 컴포넌트를 갖고 있기 때문에 위치를 갖고.
그 하위의 컴포넌트들을 갖게되면서 물리나 기타 등등에 대한 기능을 부여받는것이다.


이번 강의에서 우리는 탱크를 컨트롤할건데, 
Character엑터를 가져다 쓰면 필요 없는 기능이 많기 때문에 Pawn 클래스에 필요한 컴포넌트를 붙여서 기능을 붙여볼거다.

<font color="#9bbb59">그럼 왜 Actor로 안하고 Pawn을 하냐??</font>
Pawn은 
- controller를 가질수 있고
- Possess 가능
- 입력을 받을 수 있고
- AI가 조종이 가능하기 때문

pawn 기본 코드 구조
```cpp
class TOONTANKS_API ABasePawn : public APawn
{
	GENERATED_BODY()

public:
	// Sets default values for this pawn's properties
	ABasePawn();

protected:
	// Called when the game starts or when spawned
	virtual void BeginPlay() override;

public:	
	// Called every frame
	virtual void Tick(float DeltaTime) override;

	// Called to bind functionality to input
	virtual void SetupPlayerInputComponent(class UInputComponent* PlayerInputComponent) override;

};
```

나머지는 전부 컴포넌트나 엑터에서 본것들인데
