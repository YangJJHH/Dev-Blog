
레벨에 있는 모든 건  Actor이기 때문에 Actor를 상속 받아야할거고

가져야할 컴포넌트
- CapsuleComponent : 충돌과 위치, 루트컴포넌트
- StaticMeshComponent :  보여야 하니

1. Actor로 클래스를 만들고
2. 스태틱 메쉬 컴포넌트를 생성해주자
```c
AProjectile::AProjectile()
{
 	// Set this actor to call Tick() every frame.  You can turn this off to improve performance if you don't need it.
	//PrimaryActorTick.bCanEverTick = true;

	Mesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
	RootComponent = Mesh;
}
```

참고로 PrimaryActorTick 사용안하다 해서 false로
이후 이 클래스 기반으로 블루프린트 만들고 메쉬를 설정하자
