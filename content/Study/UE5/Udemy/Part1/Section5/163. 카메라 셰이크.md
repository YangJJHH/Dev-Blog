# 그럼 이제 이 설정한 CameraShake 블루프린트 클래스는 코드에서 어떻게 불러와 사용할까?

우리가 만든 블루프린트 클래스는 Legacy라서
기존 `MatineeCameraShake`를 지원하기 위해 `ULegacyCameraShake`가 남아 있는 거다.

따라서 코드에서 부를땐 TSubclassOf\<UCameraShakeBase\>를 통해 블루프린트 클래스를 담아줘야 한다
```cpp
UPROPERTY(EditAnywhere, Category = "Camera")
TSubclassOf<class UCameraShakeBase> CameraShake;
```

이후 카메라쉐이크를 할 부분에서 PlayerController를 가져와 PlayerController의 ClientPlayCameraShake() 함수를 통해 Camerashake 클래스를 넘겨주면 된다.
```cpp
auto PlayerController = GetWorld()->GetFirstPlayerController();
PlayerController->ClientPlayCameraShake(CameraShake);
```
