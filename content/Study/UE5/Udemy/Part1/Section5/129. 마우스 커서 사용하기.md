# 이번엔 커서위치에서 히트 결과를 받아오자!

이전 섹션에서 라인 트레이스, 스위핑에 대해 이미 한번 진행했었지만 복습을 하자면

라인 트레이스를 하려면 우선 트레이싱에 사용할 채널을 설정해야하고
방향을 정해서 레이를 쏘고 정해진 채널이 있는지 검출하는 방식이다.
참고로 해당하는 채널에 Collision Preset이 block으로 되어야 트레이싱에 걸린다
![[Pasted image 20260713233550.png]]


지금 같은 경우는 nearPlane상의 마우스 위치를 구하고 카메라로 부터 해당점의로의 방향의 레이를 쏘면 되겠다.

그럼 마우스 위치는 어떻게 가져올까?

바로 이함수를 써서 가져오면 되겠다.

```cpp
bool APlayerController::GetHitResultUnderCursor(
	ECollisionChannel TraceChannel, 
	bool bTraceComplex, 
	FHitResult& HitResult
	)
```
1.  검사 할 채널
2.  복잡한 검사? true면 삼각형 폴리곤단위로 검사. 아니면 Capsul,Box,simpleCollision 대상으로
3.  충돌 정보

```cpp
	FHitResult hit;
	if ( PlayerController->GetHitResultUnderCursor(ECC_Visibility, false, hit) )
	{
		DrawDebugSphere(GetWorld(), hit.ImpactPoint, 20.0f, 10, FColor::Red, false, -1.0f);
	}
```
그럼 다음과 같이 월드상 마우스 커서가 충돌하는 지점에 구를 그릴 수 있다.
참고로 duration을 -1,0f로 주면 한 프레임만 그리고 사라지기 때문에 겹쳐보이지 않는다.
