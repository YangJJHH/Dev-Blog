
우선 패배 조건은 탱크가 죽는것, 승리 조건은 타워가 모두 없어지는것

```cpp
	UFUNCTION(BlueprintImplementableEvent)
	void GameOver(bool bWonGame);
```
그래서 위와 같은 함수를 만들어 승패를 둘다 처리하도록 만들자
내부 구현은 블루프린트에서

패배는 쉽게 ActorDied에서 탱크가 죽은거면 호출하면 되고
Tower는 갯수를 체크해야 하기 때문에

```cpp
void AToonTanksGameMode::CheckTowerCount()
{
	int32 Count = 0;
	for (TActorIterator<ATower> it(GetWorld(), ATower::StaticClass()); it; it++)
	{
		++Count;
	}

	TowerRemain = Count;
}
```

이렇게 TActorIterator 해당 이터레이터로 월드에 해당하는 클래스 타입 엑터를 모두 순회할 수 있다.


그래서 ActorDied 내부에 이렇게 구현
```cpp
if (DeadActor == GetWorld()->GetFirstPlayerController()->GetPawn())

		}
```
