

탱크,터렛 모두 죽을때 죽음 이펙트가 나와야 하므로, BasePawn에 구현하자.
149. 타격 파티클과 동일하게 해당 위치에 스폰 하는 개념이므로

블루 프린트에서 접근 가능하세 파티클 시스템 포인터 하나 만들어두고
``` C
	UPROPERTY(EditAnywhere)
	TObjectPtr<class UParticleSystem> DestroyEffect;
```

이후 HandleDestruction에서 해당 이펙트를 생성시켜주면 된다
``` C
void ABasePawn::HandleDestruction()
{
	if (DestroyEffect)
	{
		UGameplayStatics::SpawnEmitterAtLocation(this, DestroyEffect, this->GetActorLocation(), this->GetActorRotation());
	}
}
```
