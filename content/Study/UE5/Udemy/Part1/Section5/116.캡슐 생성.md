
언리얼에서는 컴포넌트를 C++코드에서도 생성할 수 있다.
``` C
CreateDefaultSubobject<Type>(TEXT("컴포넌트 이름"))
```

그래서 생성자에서 이렇게 루트컴포넌트를 지정할수있다
``` C
CapsuleComp = CreateDefaultSubobject<UCapsuleComponent>(TEXT("Capsule"));
RootComponent = CapsuleComp;
```
