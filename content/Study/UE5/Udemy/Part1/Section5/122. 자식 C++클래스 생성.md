### 그럼 탱크만 가져아 할 기능은 뭐가 있을까?

첫번쨰로 탱크를 포커스하는 카메라
![[Pasted image 20260712163712.png]]

1.카메라
2.스프링암
이 두가지 컴포넌트가 필요하다

***스프링암은 자식 컴포넌트를 일정 거리만큼 뒤에 붙여주는 막대***
```
Character
│
├── Capsule (Root)
│
└── SpringArm
      │
      └── Camera
```

그래서 카메라가 스프링암 자식 컴포넌트로 들어간다

``` C
ATank::ATank()
{
	SpringArm = CreateDefaultSubobject<USpringArmComponent>(TEXT("SpringArm"));
	SpringArm->SetupAttachment(RootComponent);

	Camera = CreateDefaultSubobject<UCameraComponent>(TEXT("Camera"));
	Camera->SetupAttachment(SpringArm);
}
```
이런식으로 구성해주고

이전에 우리가 만들었던 탱크는 BasPawn 기반이기 때문에 새로 Tank기반으로 만들어야하는데.
아예 처음부터 새로 만들면 다시 세팅을 해줘야하기 때문에

쉽게 세팅하는 법이 있다!

우선 BasePawn 기반으로 만든 탱크 블루프린트를 열고
classSettings 누르고 우측에 classOption에서 Parentclass를 우리가 새로 만든 Tank로 바꿔주면 된다.
![[Pasted image 20260712170420.png]]


여기서 주의할점은
스프링 암의 위치 회전을 통해 카메라를 제어해야지
카메라 컴포넌트 자체를 직접 제어하면 안된다.
