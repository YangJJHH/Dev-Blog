
이제 드디어 탱크를 움직여 보자
이번에는 AddActorLocalOffset() 이라는 함수로 엑터를 움직여볼거다.
근데 실무에서는 보통 해당 함수로 움직임을 조작하지는 않음.


```cpp
void ATank::Move(float Value)
{
	UE_LOG(LogTemp, Display, TEXT("%f"),Value);

	FVector deltaVec(0.f);
	deltaVec.X = Value;
	AddActorLocalOffset(deltaVec);
}
```

해당 함수는 엑터의 로컬 좌표계를 기준으로 인자로 받은 오프셋만큼 더해서 이동시키는 함수


```cpp
void AActor::AddActorLocalOffset(FVector DeltaLocation, bool bSweep, FHitResult* OutSweepHitResult, ETeleportType Teleport)
```

해당 함수는 실제로 기본값을 갖는 인수가 더잇는데
bSweep이 켜져있으면 충돌을 감지하고 이동하는 방향에 충돌이 있을경우, 이전 프레임으로 위치를 되돌린다.
