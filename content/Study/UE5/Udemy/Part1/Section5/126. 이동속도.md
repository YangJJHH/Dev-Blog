이제 Move함수를 DeltaTime을 통해 프레임관 상관없이 속도를 제어해보자

그럼 Move함수에서 DeltaTime을 사용해야하는데,
어떻게 가져올까?
```c
UGameplayStatics::GetWorldDeltaSeconds(this);
```
해당 함수를 통해 가져올수있따

```c
void ATank::Move(float Value)
{
	UE_LOG(LogTemp, Display, TEXT("%f"),Value);

	double deltaTime = UGameplayStatics::GetWorldDeltaSeconds(this);

	FVector deltaMove(0.f);
	deltaMove.X = Value * Speed * deltaTime;

	AddActorLocalOffset(deltaMove);
}
```

Value는 -1.0 ~ 1.0 값이기 때문에
1초동안 움직일 거리를 Speed라고 가정하고 deltaTime을 곱해주면 프레임에 상관없이 일정하게 움직이게 된다.
