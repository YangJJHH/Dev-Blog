
이제 우리는 Damga Evnet를 어떨떄 발생시켜야 할지 정해야한다

그럼 Event를 어떻게 발생시킬까?
해당 함수를 호출해 
``` C
static float ApplyDamage( 
	AActor* DamagedActor, 
	float BaseDamage, 
	AController* EventInstigator, 
	AActor* DamageCauser, 
	TSubclassOf<UDamageType> DamageTypeClass );
```
마찬가지로 OnTakeAnyDamage라는 콜백 인자와 동일하다. 그래서 해당 함수가 호출되면
OnTakeAnyDamage가 호출되고 거기에 연결된 콜백이 호출되는 구조

참고로 마지막에 인자에 TSubclassOf\<UDamageType\> 로 클래스 정보를 넘겨줘야하는데
이떄 StaticClass를 사용한다

### `StaticClass()`
해당 클래스의 **런타임 타입 정보(RTTI 역할을 하는 Unreal의 UClass 객체)** 를 반환하는 함수입니다. 
주의할점
해당 클래스의 객체가 아니라, 해당 클래스의 정보를 나타내는 UClass 객체


### 호출
우선 인자에서 AController* EventInstigator 즉 데미지를 입힌 주체의 Controller를 알아야하기 때문에 BasePawn에서 Fire할떄 발사체에 SetOwner를 해주자

``` C
void ABasePawn::Fire()
{
	FVector Location = GetSpawnProjectileSpawnPoint();
	FRotator Rotation = ProjectileSpawnPoint->GetComponentRotation();

	auto Projectile = GetWorld()->SpawnActor<AProjectile>(ProjectileClass, Location, Rotation);
	Projectile->SetOwner(this);
}
```

이후 발사체 클래스의 OnComponentHit에서 ApplyDamage등록
GetInstigatorController 이걸로 쉽게 가져올수 있음

``` C
void AProjectile::OnHit(UPrimitiveComponent* HitComp, AActor* OtherActor, UPrimitiveComponent* OtherComp, FVector NormalImpulse, const FHitResult& Hit)
{
	auto MyOwner = GetOwner();
	if (MyOwner == nullptr) return;

	auto Instigator = MyOwner->GetInstigatorController();
	UGameplayStatics::ApplyDamage(OtherActor, Damage, Instigator, this, UDamageType::StaticClass());
}
```

이후 연결된 콜백 함수에 데미지를 입었을떄 처리를 하자.
HealthComponent

``` C 
void UHealthComponent::DamageTaken(AActor* DamagedActor, float Damage, const UDamageType* DamageType, class AController* Instigator, AActor* DamageCauser)
{
	if (Damage <= 0.f) return;
	
	Health -= Damage;
	UE_LOG(LogTemp, Warning, TEXT("Health : %f"), Health);
}
```

이후 발사체가 충돌해도 게속 유자하기 때문에 충돌하면 사라지게 하자
``` C
Destroy();
```
