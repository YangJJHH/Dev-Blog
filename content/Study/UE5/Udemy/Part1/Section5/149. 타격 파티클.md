
타격 파티클을 만들기 위해선 Particle System 이 필요하다

우선 에셋에서 Effect를 클릭하면 파티클 시스템 에디터 열린다.
![[Pasted image 20260718172046.png]]

# 그럼 C++ 코드에서 이 파티클 시스템을 어떻게 불러들일까?

우선  헤더에서 이렇게 변수를 선언해주고
```cpp
UPROPERTY(EditAnywhere, Category = "Effect")
TObjectPtr<class UParticleSystem> HitParticles;
```

그 후 블루프린트에서 메쉬처럼 연결해줄수있다
![[Pasted image 20260718172510.png]]


이후 해당 함수를 통해 파티클을 생성 할 수 있다.
이름이 SpawnParticle이 아닌 이유는, Partitlce은 개별입자를 뜻하고
Emitter는 그 파티클을 방출하는 시스템을 뜻한다.
```cpp
UGameplayStatics::SpawnEmitterAtLocation(
	this, 
	HitParticles, 
	this->GetActorLocation(), 
	this->GetActorRotation());
```

근데 찾아보니 위의 방식은 언리얼의 예전 이펙트 방식인 Cascade이고

요즘은 나이아가라 라는 이펙트 시스템을 사용한다 함

나이아가라 사용 예
```cpp
UNiagaraFunctionLibrary::SpawnSystemAtLocation(
    GetWorld(),
    ExplosionSystem,
    GetActorLocation());
```
