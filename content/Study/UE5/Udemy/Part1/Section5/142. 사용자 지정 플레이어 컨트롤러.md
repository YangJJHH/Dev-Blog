강의에는 없지만 우선 나같은 경우는 마우스 커서가 안보이니깐 탱크 회전할때 불편해서 마우스 커서를 보여주게 설정
```cpp
void AToonTanksPlayerController::BeginPlay()
{
	Super::BeginPlay();

	bShowMouseCursor = true;

	FInputModeGameAndUI InputMode;
	SetInputMode(InputMode);
}
```
**UI와 게임 입력을 정상적으로 함께 사용하고 싶다** → `SetInputMode()`도 함께 변경하는 것이 권장.

그 다음 엑터가 죽으면 GameMode에서 호출해서 입력과 마우스 커서를 안보이는 함수를 생성

```cpp
void AToonTanksPlayerController::SetPlayerEnabledState(bool bPlayerEnabled)
{
	if (bPlayerEnabled)
	{
		bShowMouseCursor = true;
		GetPawn()->EnableInput(this);
	}
	else
	{
		bShowMouseCursor = false;
		GetPawn()->DisableInput(this);
	}
	
}
```

그 다음 GameMode에서 이제 엑터가 죽었을때 저 함수를 false로 호출하도록
