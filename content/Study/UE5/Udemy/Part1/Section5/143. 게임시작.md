# Timer Delegate : 어떻게 콜백에 인자를 넘길까?
이전에 우리가 TImerManger로 SetTimer할때는 그냥 인자 없는 콜백을써서 바로 바인딩했지만

만약 어떤 인자를 같이 콜백에서 받고 싶다면,
```c
FTimerDelegate delg = FTimerDelegate::CreateUObject(this, callback, args,,,);
```
와 같이 델리게이트 객체를 만들어 원하는 콜백 함수와 인자를 세팅해주면된다.

그래서 GameMode에 다음과 같은 함수를 만들어 BeginPlay에서 호출하도록 하자
```c
void AToonTanksGameMode::HandleGameStart()
{
	auto TankController = Cast<AToonTanksPlayerController>(GetWorld()->GetFirstPlayerController());
	TankController->SetPlayerEnabledState(false);

	
	FTimerDelegate TimeDelegate = FTimerDelegate::CreateUObject(
		TankController, 
		&AToonTanksPlayerController::SetPlayerEnabledState, 
		true);

	FTimerHandle TimeHandle;
	GetWorld()->GetTimerManager().SetTimer(TimeHandle, TimeDelegate,StartDelay, false);
}
```

타이머 델리게이트를 만들어 탱크 컨트롤러의 활성화 함수를 바인딩해서 true를 넘겨주도록하고
SetTimer로 타이머를 시작한다
