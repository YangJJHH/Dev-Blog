# Tower는 기본적인 기능인 Tank를 게속 바라보도록 할것이다

우선 BasePawn으로 derived 된 C++ 클래스를 만들고

그럼 Tick 함수가 필요하겠고
그 다음 Tank의 위치가 필요할것이다

그럼 Tank의 위치는 어떻게 가져올까?
바로 이함수를 사용하면된다

```c
// UGameplayStatics::GetPlayerPawn()
static APawn* GetPlayerPawn(
    const UObject* WorldContextObject,
    int32 PlayerIndex
);
```

실제 사용
```c
void ATower::BeginPlay()
{
	Super::BeginPlay();
	Tank = Cast<ATank>(UGameplayStatics::GetPlayerPawn(this, 0));
}
```

이제 탱크의 위치를 알아냈으니 탱크와의 거리가 일정 거리이내 일떄만 포탑이 회전하도록하자
우선 포탑과 탱크 사이의 거리를 구하고
그 거리가 FireRange 미만이면 회전하도록 하자

회전은 이전에 BasePawn구현했던 함수 그대로 사용
```c
	// Check
	float Distance = FVector::Dist(GetActorLocation(), Tank->GetActorLocation());

	if (Distance < FireRange)
	{
		RotateTurret(Tank->GetActorLocation());
	}
```
