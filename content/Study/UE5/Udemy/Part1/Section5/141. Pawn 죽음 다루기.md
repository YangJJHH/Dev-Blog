
우선 3가지 필요할것이다
1. HealthComponent에서 체력이 0이되면 GameMode에 특정 함수를 호출해서 죽음을 알린다.
2. GameMode에 그 함수를 만들어 엑터가 죽었다는것을 알 수 있도록한고 관련 처리를 한다.
3. GameMode에서 그 죽은 엑터에 죽음 관련 함수를 호출해 엑터가 사라질떄의 처리를한다

우선 BasePawn에 죽음에 관한 함수
```cpp
virtual void HandleDestruction();
```
를 만들고

GameMode클래스에
```cpp
void AToonTanksGameMode::ActorDied(AActor* DeadActor)
{
	basePawn->HandleDestruction();
}

void AToonTanksGameMode::BeginPlay()
{
	Super::BeginPlay();

	basePawn = Cast<ABasePawn>(UGameplayStatics::GetPlayerPawn(this,0));
}
```
위와 같이 GetPlayerPawn을 이용해 Pawn을 얻어와 ActorDied가 호출되었을때 각자의 HanldDestruction 함수를 호출하도록 해준다

그럼 이제 HealthComponent에서 체력이 0이 되었을때 GameMode의 ActorDied를 호출해야한다.
```cpp
GameMode = Cast<AToonTanksGameMode>(UGameplayStatics::GetGameMode(this));
```
UGameplayStatics::GetGameMode() 이걸로 현재 사용하는 게임모드를 얻어어고

```cpp
void UHealthComponent::DamageTaken(AActor* DamagedActor, float Damage, const UDamageType* DamageType, class AController* Instigator, AActor* DamageCauser)
{
	if (Damage <= 0.f) return;
	
	Health -= Damage;
	UE_LOG(LogTemp, Warning, TEXT("Health : %f"), Health);

	if (Health <= 0.f)
	{
		GameMode->ActorDied(GetOwner());
	}
}
```
이렇게 죽었을때 GameMode의 ActorDied를 호출해주자
