
우선 이번에 우리는 탱크 상부메쉬를 마우스 커서 방향으로 회전하는걸 구현할거다
그러면 마우스 포인트가 레벨의 메쉬와 충돌했을때 그 위치를 알아야 회전값을 구할 수 있을것이다.

그럼  Controller를 통해 월드상 마우스 좌표를 알아보자

# Controller
Pawn에는 기본적으로 Controller가 있고 보이지 않는 타입이다
이 Controller는 게임이 시작될때 Pawn에 Possess된다.
그래서 탱크에 있는 카메라 시점으로 볼 수 있다.

Pawn에는 기본적으로 GetController()라는 함수가 제공되고 이를 통해 얻을 수 있다.
![[Pasted image 20260713215310.png]]

생성자에선 아직 유효한 Controller가 없기 때문에 BeginPlay에 얻어오자
우리가 필요한건 APlayerContoller* 타입인데 GetController의 반환형은 AController* 이므로 캐스팅해주자

``` c
// Header
	UPROPERTY()
	APlayerController* PlayerController;
//=================================================
// cpp
void ATank::BeginPlay()
{
	Super::BeginPlay();

	PlayerController = Cast<APlayerController>(GetController());
}
```
