
이번에는 실제 총알이 날아가게 움직여보자

여러 방법이 있는데
1. 내가 생각한 것처럼 Tick에서 직접 위치값을 변화시키는것
2. 발사체에 물리엔진을 이용해 힘을 추가해 발사시키는법
3. MoveComponent를 사용하는것
4. 마지막 언리얼엔진의 내장된 발사체 컴포넌트를 사용하는것

보통 AAA급 게임에서는 직접 Tick에서 게임코드로 총알을 구현하는데
우리는 이번에 ProjectileMovementComponent를 사용해보자

``` C
	ProjectileMovement = CreateDefaultSubobject<UProjectileMovementComponent>(TEXT("Projectile"));
	ProjectileMovement->InitialSpeed = 100.f;
	ProjectileMovement->MaxSpeed = 200.f;
```

- InitialSpeed : **발사 순간의 속도**
- MaxSpeed : 최대 속도

해당 컴포넌트는 `UpdatedComponent`를 움직인다.
`UpdatedComponent`는 따로 설정하지 않으면 기본적으로 루트컴포넌트이다.

### 재미는거
``` C
ProjectileMovement->bIsHomingProjectile = true; 
ProjectileMovement->HomingAccelerationMagnitude = 10000.f;
ProjectileMovement->HomingTargetComponent = TargetActor->GetRootComponent();
```
이걸로 유도탄도 만들 수 있음, HomingAccelerationMagnitude 이값이 클수록 더 유도됨
