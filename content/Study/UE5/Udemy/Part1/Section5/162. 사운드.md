# 이번엔 발사체가 충돌할때, pawn이 죽을떄 사운드를 재생시켜보자


사운드는 USoundBase를 통해 C++ 코드에서 참조할 수 있다.
```cpp
UPROPERTY(EditAnywhere)
TObjectPtr<USoundBase> LaunchSound;
```

마찬가지로 블루프린트로 사운드를 설정해주자
![[Pasted image 20260727222331.png]]

그럼 코드에서 어떻게 재생시킬까?
UGameplayStatics::PlaySoundAtLocation() 해당 함수를 통해 원하는 지점에서 사운드를 재생시킬수있다.

```cpp
UGameplayStatics::PlaySoundAtLocation(this, LaunchSound, GetActorLocation());
```
