
이제 총알을 어떻게 레벨에 생성할지 알아보자

우리는 C++ 코드를 통해, C++로 만든 클래스를 기반한 블루프린트 총알을 생성해야한다.
왜냐하면 블루프린트에 메쉬정보가 있기 때문

# 그렇다면 C++에서 블루프린트기반 객체를 어떻게 인스터스할까?

언리얼에는 TSubofClass\<Type\>이란게 존재한다.
여기에는 Type을 상속받는 클래스, Type을 기반으로 생성한 블루프린트를 담을수있다.

즉 우리가 만든 블루프린트를 C++에서 멤버로 들고 있을 수 있게 해줄 수 있다.
```cpp
UPROPERTY(EditDefaultsOnly, Category = "Combat")
TSubclassOf<class AProjectile> ProjectileClass; // forward-declaration
```
그래서 이런식으로  BasePawn.h에 발사체 클래스를 담을 변수를 선언해준다.

그러면 이제 블루프린트에서 아래처럼 c++클래스, 블루프린트 클래스 모두 선택할수있는걸 볼 수 있다

주의할점은 이건 객체가 아니라 클래스 타입을 담는 변수이다.


# 월드에 Actor를 생성하는법

UWorld::SpawnActor를 통해 생성 할 수 있다
![[Pasted image 20260715232520.png]]

SpawnActor에는 생성할 객체의 C++ 클래스와, 인자로 실제 어떤 객체로 생성할지, 위치 회전 정보를 받게된다

그래서 저 꺽쇠에 있는 타입에 우리가 TSubclassOf를 저장한 클래스 타입을 넘겨주는것이다

```cpp
GetWorld()->SpawnActor<AProjectile>(ProjectileClass, Location, Rotation);
```
