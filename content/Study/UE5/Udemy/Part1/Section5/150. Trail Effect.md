
우리가 기존에 Hit Effect는 단순히 UParticleSystem을 멤버로 두고 Spawn하기만 했지만

이번에는 Trail Effect를 위해선 UParticeSystemComponent를 사용해야한다
왜냐하면 이 컴포넌트를 총알 루트 컴포넌트에 붙여서 게속 따라가면서 재생시킬거기 때문에
![[Pasted image 20260718174938.png]]


다른 컴포넌트와 동일하게 생성을 해주고
```cpp
// Header
UPROPERTY(EditAnywhere, Category = "Effect")
TObjectPtr<class UParticleSystemComponent> TrailEffectComp;

// Cpp
TrailEffectComp = CreateDefaultSubobject<UParticleSystemComponent>(TEXT("Trail"));
TrailEffectComp->SetupAttachment(RootComponent);
```

참고로 얘는 루프 이펙트임
Required 누르고 디테일 패널에 보면 있음
