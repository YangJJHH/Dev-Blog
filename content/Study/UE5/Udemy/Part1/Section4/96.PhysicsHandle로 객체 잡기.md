
Physics Handle은 "현재 내가 무엇을 잡고 있는지"를 관리하는 컴포넌트
그래서 잡는 주체 액터에 붙여야한다

### GrabComponentAtLocationWithRotation()
물체를 잡기위해 처음에 세팅하는 함수

```cpp
PhysicsHandle->GrabComponentAtLocationWithRotation(
	outHit.GetComponent(), // 컴포넌트
	NAME_None, // 잡은 bone 이름
	outHit.ImpactPoint, // 위치
	outHit.GetComponent()->GetComponentRotation()); // 회전
```

회전까지 유지하면서 잡는다.
FPS 게임에서 많이 사용한다.

그리고 처음 세팅 한 이후 매 Tick()에서 SetTargetLocationAndRotation() 함수로 위치와 회전을 게속 세팅해줘야 잡은상태로 따라다니게 된다.

```cpp
// Tick 함수 내부에서
PhysicsHandle->SetTargetLocationAndRotation(TargetLocation, GetComponentRotation());
```

그리고 코드 컴파일 한후 실제 Grab했는데 안움직여졌는데,
물체의 Mobility 속성을 Move로 바꿔줘야 한다.
