
## UHT(UnrealHeaderTool)
- 언리얼 코드를 보면 아래처럼 UCLASS,GENERATED_BODY,UPROPERTY 등이 붙어 있는걸 볼 수 있는데
- ```cpp
  UCLASS()  
	class AMyActor : public AActor  
	{  
	GENERATED_BODY()  
	  
	UPROPERTY()  
	int32 HP;  
};
  ```

언리얼에서는 C++에 없는 다음과 같은 기능 때문에 추가로 엔진이 쓸 코드를 직접 생성해 삽입한다.
- 리플렉션 (변수/함수 정보 런타임 접근)
- GC (가비지 컬렉션)
- 블루프린트 연동
- 자동 직렬화

그래서 UCLASS,GENERATED_BODY,UPROPERTY 같은 키워드들이 있어야 UHT가 키워드를 인식해 해당 클래스를 분석하고 적절한 코드를 삽입해준다.

C++ 헤더(.h) 스캔  
→ UCLASS / UPROPERTY / UFUNCTION 찾음  
→ 추가 코드 생성 (.generated.h)

include "MyActor.generated.h"

이 파일 안에 **자동 생성된 코드** 들어있음

`UCLASS()` — “이 클래스는 엔진이 관리한다”
`GENERATED_BODY()` — “여기에 코드 꽂아줘”

그리고 중요한게 generated.h가 항상 인클루드 마지막에 포함되어야 함 이유는.
👉 UHT가 생성한 코드가
