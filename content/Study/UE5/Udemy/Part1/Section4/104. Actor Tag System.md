## 근데 한가지 의문점
이렇게 Actor Tag로 Overlap된 애들중 필터링 하는것도 가능하긴한데
애초에 Collison preset에서 overlap 할 애들만 커스텀하는게 좋지 않나?

GPT왈
하지만 더 좋은 방법은 충돌 설정을 이용하는 것입니다.

예를 들어

- `ECC_Player`
- `ECC_Enemy`
- `ECC_Interactable`

처럼 **Object Channel**을 만들고,

Collision Preset에서

- Player는 Enemy만 Overlap
- Enemy는 Player만 Overlap
- Item은 Player만 Overlap

처럼 설정하면,

**애초에 필요 없는 Overlap 이벤트 자체가 발생하지 않습니다.**

즉,

```
void UMyComponent::OnOverlap(...){    // 들어오는 것은 이미 Enemy뿐}
```

가 되므로 코드도 간단해지고 불필요한 이벤트도 줄어듭니다.

### 그럼 Actor Tag는 언제 쓰나?

태그는 **Collision으로 구분하기 어려운 논리적인 분류**에 사용하면 좋습니다.

예를 들어

- 적 중에서도 `Boss`
- 적 중에서도 `Flying`
- NPC 중에서도 `QuestNPC`

처럼 **같은 Collision Channel을 쓰지만 게임 로직상 구분**이 필요할 때입니다.

```
if (OtherActor->ActorHasTag(TEXT("Boss"))){    // 보스 전용 처리}
```
