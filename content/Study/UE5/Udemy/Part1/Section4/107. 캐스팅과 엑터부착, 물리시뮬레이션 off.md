
가고일을 벽에 넣었을떄 부자연스러운 모습때문에, overlap 됐을 시 부착되도고 물리시뮬레이션 off되도록 해보자

우선 해당 엑터의 상위 컴포넌트인 PrimitiveComponent를 가져와야 시뮬레이션을 off할수 있기 때문에, RootComponent를 가져와 캐스팅을 해준다.

<mark style="background:#d3f8b6">주의 언리얼 오브젝트는 Cast를 쓴다</mark>

## GetRootComponent

- 컴포넌트 계층상 트리의 최상위 컴포넌트를 가져온다
- 현재 가고일의 상위 컴포넌트는 SceneComponent이므로 PrimitiveComponent로 캐스팅
``` C
  UPrimitiveComponent* pPrimitive = 
  Cast<UPrimitiveComponent>(Actor->GetRootComponent());
```

## AActor::AttachToComponent

- 우선 엑터에 부착하는 함수이다
- this로 현재 컴포넌트를 전달하고
- 두번째 인자로 FAttachmentTransformRules를 전달해야하는데 이건 구조체이다.
	- 어떻게 부착되어야 할지에 대한 정보

``` C
pPrimitive->AttachToComponent(this, FAttachmentTransformRules::KeepWorldTransform);
```

## SetSimulatePhysics

- 엑터의 물리 시뮬레이션을 세팅하는 함수

``` C
pPrimitive->SetSimulatePhysics(false);
```
