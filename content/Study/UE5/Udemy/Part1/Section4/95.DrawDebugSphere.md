# 디버그 구체를 그리는 법

```cpp
DrawDebugSphere(GetWorld(), End, 10, 10, FColor::Red, true, 5.0f);
// 월드, 구 중심, 반지름, 구 분할갯수, 색, 게속 지속 여부, 라이프타임
```


다음과 같이 Hit에 대한 정보를 바탕으로 2개의 위치정보가 있어 2개 구체를 그려봤다.
```cpp
FVector loc = outHit.Location;
FVector impactloc = outHit.ImpactPoint;

DrawDebugSphere(GetWorld(), loc, 10, 10, FColor::Blue, false, 5.0f);
DrawDebugSphere(GetWorld(), impactloc, 10, 10, FColor::Red, false, 5.0f);
```

outHit..Location : 실제 구가 물체와 충돌하는 위치
