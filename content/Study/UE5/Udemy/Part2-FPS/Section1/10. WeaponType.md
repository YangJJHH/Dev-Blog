
## 이제 우리가 사용할 무기를 식별할 수 있게 해야한다

VS에서 ShooterGamePlayTags.h, ShooterGamePlayTags.cpp를 만들어주자

우리는 총 타입을 언리얼 태그 시스템을 이용할거다
언리얼의 GamePlayTag를 만드는 방법은

새로운 ShooterGamePlayTags.h,ShooterGamePlayTags.cpp를 만들고

헤더에 아래와 같이 선언하고
```cpp
namespace ShooterTags
{
	UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_WeaponType_None);
	UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_WeaponType_Pistol);
	UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_WeaponType_Rifle);
}
```

cpp에 이렇게 정의하면 된다
```cpp
namespace ShooterTags
{
	UE_DEFINE_GAMEPLAY_TAG(TAG_WeaponType_None, "Weapon.Type.None");
	UE_DEFINE_GAMEPLAY_TAG(TAG_WeaponType_Pistol, "Weapon.Type.Pistol");
	UE_DEFINE_GAMEPLAY_TAG(TAG_WeaponType_Rifle, "Weapon.Type.Rifle");
}
```

그 다음 Weapon.h로 가서 이렇게 FGameplayTag 형 변수를 선언해서 BP에서 태그를 설정해줄 수 있다.
```cpp
	UPROPERTY(EditAnywhere, Category = "Weapon")
	FGameplayTag WeaponType;
```

근데 GamePlaytTags 쓰려면 얘도 모듈 추가해줘야함 Build.cs에 추가
```c#
PublicDependencyModuleNames.AddRange(new string[] { "Core", "CoreUObject", "Engine", "InputCore", "EnhancedInput", "GameplayTags" });
```
