### 1. Root Bone

**IK 계산을 시작할 기준이 되는 뼈의 시작점**
```
Root Bone = UpperArm
                ↓
UpperArm → Forearm → Hand
```
즉,

> "여기부터 아래쪽 뼈들을 IK 계산해."

보통 팔이면 `upperarm`, 다리면 `thigh` 같은 뼈를 넣는다

### 2. Tip Bone

반대로 **IK 체인의 끝 뼈**

```
UpperArm → Forearm → Hand
                         ↑
                      Tip Bone
```
즉,

> Root Bone부터 Tip Bone까지의 뼈들을 FABRIK이 조정한다.

### 3. Effector Transform 

목표점

예를 들어 손을 총의 소켓에 가져다 놓고싶으면 Effect Transform =  "총 소켓 위치"

### 4. Effector Target

이건 **Effector Transform을 어디 기준으로 좌표를 계산할지**

강의에서는 hand_r 본을 넣어놨는데, Effector Transform을 hand_r 기준으로 계산해서 넣겠다는 뜻.

### 5. Effector Location Space

Effector Transform의 **위치 좌표가 어느 좌표계 기준인지** 정하는 것
```
World Space
Component Space
Bone Space
```

강의 기준으로는 hand_r을 넣었기 때문에 BoneSpace가 될것

그래서 강의에서 다음과 같은 함수를 Tick마다 호출해 FABRIK_SoketTransform이란 변수를 업데이트한다

```cpp
	if (IsValid(CombatComp) && CombatComp->CurrentWeapon)
	{
		FABRIK_SocketTransform = CombatComp->CurrentWeapon->GetMesh3p()->GetSocketTransform("FABRIK_Socket", RTS_World); // Wolrd Space로 가져오고

		FVector OutLocation;
		FRotator OutRotation;
			GetMesh()->TransformToBoneSpace( //  Bone Space로 변환
			"hand_r",
			FABRIK_SocketTransform.GetLocation(),
			FABRIK_SocketTransform.GetRotation().Rotator(),
			OutLocation, OutRotation);

		FABRIK_SocketTransform.SetLocation(OutLocation);
		FABRIK_SocketTransform.SetRotation(OutRotation.Quaternion());
	}
```

그래서 우리가 만든 FABRIK_Transform을 Effector Transform으로 넣어주고
