## 이제 실제로 무기를 손에 부착시켜보자!

Weapon 클래스에 다음과 같은 함수를 만들고
```cpp
	void AttachToOwningPawn() const;
```

그 다음 함수를 구현하기전에 여기서 필요한건 Owenr와 그 폰이 갖고있는 메쉬1p,메쉬3p 등등이 있을것이다.
이거는 ShooterCharcter를 통해 가져올 수 있는데, 강의에서는 이렇게 의존성을 갖지 않고 인터페이스를 통해 제공해보겠다고 한다.

다음과 같이 인터페이스 두 함수를 추가하고, 해당함수는 ShooterCharacter에서 단순히 매쉬를 반환하는 기능을 담당한다.
```cpp
	UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
	USkeletalMeshComponent* GetMesh1P() const;

	UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
	USkeletalMeshComponent* GetMesh3P() const;
```

그 다음 Weapon으로 돌아와서
```cpp
void AWeapon::SetMeshVisibilites(APawn* OwningPawn)
{
	if (OwningPawn->IsLocallyControlled())
	{
		Mesh1p->SetHiddenInGame(false);
		Mesh3p->SetHiddenInGame(true);
	}
	else
	{
		Mesh1p->SetHiddenInGame(true);
		Mesh3p->SetHiddenInGame(false);
	}
}
```
 IsLocallyControlled 은 현재 내가 조종하는 캐릭터인지를 확인하는 조건이고
 내가 조종하는 캐릭터의 총일때는 1인칭용, 아닐때는 3인칭용을 보여준다.


```cpp
void AWeapon::AttachToOwningPawn()
{
	APawn* OwningPawn = GetInstigator();
	if (!IsValid(OwningPawn) || !OwningPawn->Implements<UPlayerInterface>()) return;

	SetMeshVisibilites(OwningPawn);

	const FName AttachPoint = IPlayerInterface::Execute_GetWeaponAttachPoint(OwningPawn, WeaponType);
	USkeletalMeshComponent* PawnMesh1P = IPlayerInterface::Execute_GetMesh1P(OwningPawn);
	USkeletalMeshComponent* PawnMesh3P = IPlayerInterface::Execute_GetMesh3P(OwningPawn);

	Mesh1p->AttachToComponent(PawnMesh1P, FAttachmentTransformRules::KeepRelativeTransform, AttachPoint);
	Mesh3p->AttachToComponent(PawnMesh3P, FAttachmentTransformRules::KeepRelativeTransform, AttachPoint);
}
```
이제 실제 부착하는 함수인데
보면 IPlayerInterface를 통해 ShooterCharacter의 내부 구현된 인터페이스 함수들을 호출 할 수 있다.

그 다음 컴뱃컴포넌트에서 스폰후 어태치 시켜주고
```cpp
void UCombatComponent::SpawnInventory()
{
	AWeapon* NewWeapon = SpawnWeapon(DefaultWeaponClass);

	if (!IsValid(NewWeapon)) return;

	NewWeapon->AttachToOwningPawn();
}
```

근데 중요한건!! 여기서 데디서버 - 클라 멀티플레이 관점을 고려해야한다는거다
SpawInvetroy는 사실상 서버에서만 돌아가는 로직이다.
왜냐 SpawnWeapon 내부에 서버일때만 Spaw되도록 했기 때문에 
클라이언트는 2번쨰 조건에서 튕겨서 어태치가 안될것임.

그래서 클라이언트에서는 Weapon이라는 엑터가 서버를 통해 생성되고 클라이언트한테 복제되는시점에 어태치를 해주도록 해야한다.

그래서 다음과 같은 함수를 만든다
OnRep_변수명() 을 하면 해당 변수가 네트워크를 통해 복제되고 콜백되는 함수이다.

```cpp
virtual void OnRep_Owner() override;
```

그래서 여기서 다시 어태치 해줘야함
```cpp
void AWeapon::OnRep_Owner()
{
	Super::OnRep_Owner();
	AttachToOwningPawn();
}
```
