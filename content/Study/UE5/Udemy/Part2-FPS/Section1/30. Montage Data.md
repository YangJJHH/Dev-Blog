
# 게임 플레이에서 애니메이션을 어떻게 재생할지를 제어하기 위한 컨테이너/재생 시스템

코드 흐름에서 쉽게 애니메이션을 제어할수 있는 시스템이라 한다.

우선 WeaponData에 다음과 같이 몽타주를 저장할 구조체를 생성
```cpp
USTRUCT(BlueprintType)
struct FMontageData
{
	GENERATED_BODY()

	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
	TObjectPtr<UAnimMontage> EquipMontage = nullptr;

	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
	TObjectPtr<UAnimMontage> RelodMontage = nullptr;

	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
	TObjectPtr<UAnimMontage> FireMontage = nullptr;
};
```


애니메이션과 동일하게 1인칭,3인칭 마다 몽타주를 추가하기 위해 Tmap을 생성하고
무기에 따른 몽타주도 추가해주자

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "FPS|WeaponData|FirstPerson")
TMap<FGameplayTag, FMontageData> FirstPersonMontage;

UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "FPS|WeaponData|ThirdPerson")
TMap<FGameplayTag, FMontageData> ThirdPersonMontage;

UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "FPS|WeaponData|Weapons")
TMap<FGameplayTag, FMontageData> WeaponMontage;
```
