## 이제 무기를 스폰해보자, 이 작업은 CombatComponent의 역할이다


헤더에 다음과 같이 디폴트 무기 클래스 및 Spawn함수를 선언해준다
```cpp
	UPROPERTY(EditDefaultsOnly, Category = "FPS|Weapon")
	TSubclassOf<AWeapon> DefaultWeaponClass;

	AWeapon* SpawnWeapon(TSubclassOf<AWeapon> WeaponClass) const;
```

```cpp
AWeapon* UCombatComponent::SpawnWeapon(TSubclassOf<AWeapon> WeaponClass) const
{
	AActor* Owner = GetOwner();
	if(!IsValid(Owner)) return nullptr;
	
	if (Owner->GetLocalRole() < ROLE_Authority) return nullptr;

	FActorSpawnParameters SpawnInfo;
	SpawnInfo.Owner = Owner;
	SpawnInfo.Instigator = Owner->GetInstigator();
	SpawnInfo.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
	
	return Owner->GetWorld()->SpawnActor<AWeapon>(WeaponClass, SpawnInfo);
}
```

하나씩 코드를 보자면 GetLocalRole 및 Authority는 아래에 자세히 설명할껀데 ROLE_Authority 이조건이 현재 서버가 실행중인게 아니면 리턴한다는 의미

> Owner

Owner를 캐릭터로 설정해주고, 주의할건 Owenr는 부모자식 개념이 아님. 그냥 엑터를 누가 소유하나

> Instigator

`Instigator`는 쉽게 말하면:
 **"이 Actor의 행동을 유발한 Pawn은 누구인가?"**
 특히 **투사체, 데미지, 공격 판정** 같은 곳에서 많이 사용한다.

>SpawnCollisionHandlingOverride

이건 **Spawn할 때 위치에 다른 충돌체가 있어도 어떻게 할지** 정하는 거
AlwaysSpawn 은 충돌이 있더라도 일단 Spawn해라

그 다음 일단 Inventory에서 Spawn만하고 아직 실제로 원하는 위치에는 붙이지 않고 테스트만 해보자
```cpp
void UCombatComponent::SpawnInventory()
{
	AWeapon* NewWeapon = SpawnWeapon(DefaultWeaponClass);
}
```

## GetLocalRole , Authority 에 대해

언리얼 Actor에는 **Role**이라는 개념이 있다.

대표적으로:

```
ROLE_Authority
ROLE_AutonomousProxy
ROLE_SimulatedProxy
```

대략:

```
Authority
→ 서버가 이 Actor를 권한 있게 가지고 있음

AutonomousProxy
→ 자기 자신이 조종하는 클라이언트 Actor

SimulatedProxy
→ 다른 플레이어의 Actor를 클라이언트가 보고 있음
```

```
Dedicated Server
 └─ PlayerCharacter
       Role = Authority
       ↓
    SpawnWeapon 실행 가능


Client 1
 └─ 자기 Character
       Role = AutonomousProxy
       ↓
    실행 불가

Client 1
 └─ 다른 플레이어 Character
       Role = SimulatedProxy
       ↓
    실행 불가
```

즉 Authority는 서버에서 실행중인지 확인하는 것
서버에서만 실행하도록 하고 싶을때 비교한다.
