# 이제 현재 무기에 대한 정보를 관리해보자!

```cpp
UPROPERTY(Transient, ReplicatedUsing = OnRep_CurrentWeapon)
TObjectPtr<AWeapon> CurrentWeapon;
```
마찬가지로 런타임에 변경될 정보니깐 Transient 및 복제를 위해 Replicated를 해주는데 
처음보는 ReplicatedUsing 이게 나왔다

# ReplicatedUsing
#ReplicatedUsing

이거는 의미는 똑같이 Replicated 하라는건데 해당 변수가 복제될떄 클라이언트에서 콜백될 함수를 지정할 수 있는거다.

따라서 OnRep_CurrentWeapon 라는 함수이름을 지정해주고, 해당 함수를 UFUNCTION으로 선언 및 정의 해줘야 한다.

중요한건 해당 함수는 서버에서도 동일하게 호출되는게 아니라 클라이언트에서 복제될 시점에 호출이 필요할때 클라이언트에서 호출을 바라는 함수이다. (서버쪽에서도 비슷한 처리를 하려면 따로 별도의 함수를 만들어서 처리해줘야 함)

```cpp
UFUNCTION()
void OnRep_CurrentWeapon(AWeapon* PreviousWeapon);
```

이렇게 선언할 수 있고. 인자를 생략하거나 저렇게 받을수도 있는데.
이전값에 대한 인자를 받을수도 있다

마찬가지로 GetLifetimeReplicatedProps 여기에도 등록을 해주자
```cpp
void UCombatComponent::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
	Super::GetLifetimeReplicatedProps(OutLifetimeProps);

	DOREPLIFETIME(UCombatComponent, Inventory);
	DOREPLIFETIME(UCombatComponent, CurrentWeapon);
}
```

그럼 이제 무기를 장착하는 행위를 하면 현재 무기가 복제되고, 복제되면 거기에 맞게 클라이언트에서 현재 무기에 맞는걸 보여주고 어태치시키면 되겠지?

그래서 장착 함수를 만들고
```cpp
	void Equip(AWeapon* Weapon);
```


```cpp
void UCombatComponent::Equip(AWeapon* Weapon)
{
	CurrentWeapon = Weapon;
	CurrentWeapon->AttachToOwningPawn();
}
```
위에처럼 구현 얘는 서버에서 호출될 함수로 가정

현재는 클라이언트에서 무기를 바꾸는 기능을 구현한건 아니고 그냥 단순히 Equip을 통해 CurrentWeapon을 서버에서 바꾸고 복제하는 용도

그렇다면 서버에서는 Equip을 통해 CurrentWeapon을 바꾸고 어태치 한다면

클라이언트에서 아래 함수를 통해 CurrentWeapon가 바뀌면 이전껄 숨기고 현재껄 어태치한다
```cpp
void UCombatComponent::OnRep_CurrentWeapon(AWeapon* PreviousWeapon)
{
	if (!IsValid(CurrentWeapon)) return;
	CurrentWeapon->AttachToOwningPawn();
	PreviousWeapon->SetActorHiddenInGame(false);
}
```

그 다음 DestroyInventory도 마저 구현
```cpp
void UCombatComponent::DestroyInventory()
{
	for( TObjectPtr<AWeapon>& Weapon : Inventory)
	{
		if(!IsValid(Weapon)) continue;
		Weapon->Destroy();
	}
}
```

이거는 캐릭터의 BeginDestroy 에서 호출된다
```cpp
void AShooterCharacter::BeginDestroy()
{
	Super::BeginDestroy();
	if(IsValid(CombatComp))
		CombatComp->DestroyInventory();
}
```

BeginDestroy는 보통 이 UObject가 이제 진짜 파괴될 테니, 파괴 직전에 필요한 정리를 시작하는 단계

일반적인 C++ 객체는 소멸자에서 메모리 해제를 해준다고 한다.

다만 Weapon->Destroy(); 이걸 한다고 바로 메모리에서 삭제되는건 아니고 GC에 월드에서 제거될 엑터라고 알리는 용도
