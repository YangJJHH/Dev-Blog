## 이제 실제 전투에 필요한 IA를 바인딩 해보자

우리가 IA를 바인딩할 방법은 2가지인데
1. 캐릭터에서
2. 컨트롤러에서

앞서서 우리 기본 움직이는 컨트롤러에서 했는데.
이제 캐릭터에 CombatComponent가 있으니 전투 관련 입력은 캐릭터에 바인딩하자

그냥 설계차이

그럼 ShooterCharacter에 마찬가지로 IA들을 선언하고

```cpp
	UPROPERTY(EditAnywhere, Category = "FPS|Input")
	TObjectPtr<class UInputAction> CycleWeaponAction;

	UPROPERTY(EditAnywhere, Category = "FPS|Input")
	TObjectPtr<class UInputAction> ReloadAction;

	UPROPERTY(EditAnywhere, Category = "FPS|Input")
	TObjectPtr<class UInputAction> FireWeaponAction;

	UPROPERTY(EditAnywhere, Category = "FPS|Input")
	TObjectPtr<class UInputAction> AimAction;
```


다음과 같이 바인딩
```cpp
void AShooterCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
	Super::SetupPlayerInputComponent(PlayerInputComponent);

	UEnhancedInputComponent* ShooterInputComponent = CastChecked<UEnhancedInputComponent>(InputComponent);
	ShooterInputComponent->BindAction(ReloadAction, ETriggerEvent::Started, this, &AShooterCharacter::Input_ReloadWeapon);
	ShooterInputComponent->BindAction(CycleWeaponAction, ETriggerEvent::Started, this, &AShooterCharacter::Input_CycleWeapon);
	ShooterInputComponent->BindAction(FireWeaponAction, ETriggerEvent::Started, this, &AShooterCharacter::Input_FireWeapon_Pressed);
	ShooterInputComponent->BindAction(FireWeaponAction, ETriggerEvent::Completed, this, &AShooterCharacter::Input_FireWeapon_Released);
	ShooterInputComponent->BindAction(AimAction, ETriggerEvent::Started, this, &AShooterCharacter::Input_Aim_Pressed);
	ShooterInputComponent->BindAction(AimAction, ETriggerEvent::Completed, this, &AShooterCharacter::Input_Aim_Released);
}
```

단순히 캐릭터에 바인딩할 함수들을 새로 만들었는데 쟤네 내부는 아래처럼 그냥 CombatComponent의 Initiate을 호출해주는 역할이다

```cpp
void AShooterCharacter::Input_CycleWeapon()
{
	CombatComp->Initiate_CycleWeapon();
}
```
이런식으로

그 다음 각 IA가 바인딩이 잘됐는지 로그를 찍어 확인해보자
UE_LOG는 콘솔창에 출력이되지만

GEngine->AddOnScreenDebugMessage 이거는 화면상에서 직접 출력이된다
```cpp
void UCombatComponent::Initiate_CycleWeapon()
{
	GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Green, TEXT("Cycle Weapon"));
}
```
