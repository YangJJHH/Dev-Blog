
일단 이번 강의의 목표는 캐릭터가 가만히 서있고 마우스로 바라보는 방향만 바뀔때 하체는 그대로 두고 상체만 회전하다가, 그 각도가 정해진 각도보다 넘어가면 하체가 그 방향으로 제자리에서 방향을 바꾸게 하는것이 목적

우선 Tick에서 돌아가는 아래 함수를 만들었다
```cpp
void AShooterCharacter::CalculateTurnInPlaceParameters(float DeltaTim)
{
	FVector Velocity = GetVelocity();
	Velocity.Z = 0.f;
	float Speed = Velocity.Size();
	
	bool bIsInAir = GetCharacterMovement()->IsFalling();

	// if standing still and not jumping
	if (Speed < 0.1f && !bIsInAir)
	{
		// get current aim rotation
		FRotator CurrentAimRotation(0.0f, GetBaseAimRotation().Yaw, 0.0f);

		// get delta aim rotation - the difference in rotation of my current aim from the initial aim rotation
		FRotator DeltaAimRotation = UKismetMathLibrary::NormalizedDeltaRotator(CurrentAimRotation, StartingAimRotation);

		// Store the Yaw of the delta aim rotation (AO_Yaw)
		AO_Yaw = DeltaAimRotation.Yaw;

		if (TurningStatus == ETurningInPlace::NotTurning)
		{
			InterpAO_Yaw = AO_Yaw;
		}
				
		TurnInPlace(DeltaTim);
	}
		
	
	if (Speed > 0.1f || bIsInAir)
	{
		StartingAimRotation = FRotator(0.0f, GetBaseAimRotation().Yaw, 0.0f);
		AO_Yaw = 0.0f;

		// We also need a Movement Offset Yaw to feed to our strafing blendspaces
		FRotator AimRotation = GetBaseAimRotation();
		FRotator MovementRotation = UKismetMathLibrary::MakeRotFromX(GetVelocity()); // 해당 벡터가 얼마나 회전했는지에 대한 회전값을 반환

		MovementOffsetYaw = UKismetMathLibrary::NormalizedDeltaRotator(MovementRotation, AimRotation).Yaw;
		TurningStatus = ETurningInPlace::NotTurning;
	}	

	AO_Yaw *= -1.0f;
}
```

엄청긴데 하나씩 보자면
우선 첫 조건문이 우리가 원하는 가만히 있는 상태이다
```cpp
FRotator DeltaAimRotation = UKismetMathLibrary::NormalizedDeltaRotator(CurrentAimRotation, StartingAimRotation);
```
이걸 통해서 우리가 현재 바라보고 있는 aimRotation과 회전하기전 방향의 각도 FRotator들을 각각 구해 그 각도의 델타를 구해준다.

방향이 아닌데 FRotator에도 NormalizedDeltaRotator 이걸 하는 이유는
Normalized가 크기를 1로 만드는 역할이 아닌 회전 특성상 예를들어 
```
350
10
```
이 경우 그냥 빼면 340이 나오는데 350에서 10도만 돌면된다고 나오기 때문에
-20~20처럼 범위를 정리해서 표현해준다

그래서 회전각도 델타를 구해서 Yaw값만 AO_Yaw에 저장하고,
아직 제자리 회전 전일때는 InterpAO_Yaw에 그 델타를 저장해준다

TurnInPlace 함수는 실제 제자리 회전을 하는 함수인데
여기서 직접 어떤 회전이나 애니메이션 처리를 하는것이 아닌 변수를 업데이트하면서
그 변수가 블루프린트상에서 애니메이션을 처리하는거같음
```cpp
void AShooterCharacter::TurnInPlace(float DeltaTime)
{

	if (AO_Yaw > 90.0f)
	{
		TurningStatus = ETurningInPlace::Right;
	}
	else if(AO_Yaw < -90.0f)
	{
		TurningStatus = ETurningInPlace::Left;
	}

	if( TurningStatus != ETurningInPlace::NotTurning )
	{
		InterpAO_Yaw = FMath::FInterpTo(InterpAO_Yaw, 0.f, DeltaTime, 4.f);
		AO_Yaw = InterpAO_Yaw;
		if (FMath::Abs(AO_Yaw) < 5.f)
		{
			TurningStatus = ETurningInPlace::NotTurning;
			StartingAimRotation = FRotator(0.0f, GetBaseAimRotation().Yaw, 0.0f);
		}
	}
}
```

델타가 각각 90,-90이상일때만 회전하도록해서
제자리 회전상태가 된 경우
InterpAO_Yaw 값을 0으로 보간시키고, 보간시킨 그 값을 AO_YAW에 저장하는데 이걸로 아마 애니메이션에서 제어하지 않을까 싶다. 아직 사용안해서 정확히 모르겠음

그리고 이번에 Enum타입을 새로 헤더에 생성했는데
그 방식이 특이해서 정리
Enum을 블루프린트 상에서도 노출시키고 싶으면 리플랙션 시켜야해서 UENUM으로 만들어준다
```cpp
#pragma once
#include "ShooterType.generated.h"

UENUM(BlueprintType)
enum class ETurningInPlace : uint8
{
	Left UMETA(DisplayName = "TurningLeft"),
	Right UMETA(DisplayName = "TurningRight"),
	NotTurning UMETA(DisplayName = "NotTurning")
};
```

그래서 "ShooterType.generated.h" 이것도 필요하고
특이하게 UMETA 를 붙어 노출되는 이름을 설정해줄 수 있나보다
