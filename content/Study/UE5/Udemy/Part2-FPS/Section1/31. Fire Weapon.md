
# 이제 이전에 만든 Montage를 실제 코드에서 제어해보자!

우선 CombatComponent에서 발사 키를 눌렀을떄 우리가 필요한것은

1. 로컬에서의 1인칭 메쉬 애니메이션 재생
2. 3인칭 메쉬 애니메이션 재생을 위한 서버 RPC 필요


그래서 로컬에서 발사를 처리할 함수를 만들고
```cpp
void UCombatComponent::Local_FireWeapon()
{
	if (!IsValid(CurrentWeapon) || !IsValid(WeaponData)) return;
	
	UAnimMontage* Montage1P = 
	WeaponData->FirstPersonMontage.FindChecked(CurrentWeapon->GetWeaponType()).FireMontage;
	
	USkeletalMeshComponent* Mesh1P = IPlayerInterface::Execute_GetMesh1P(GetOwner());

	if(IsValid(Montage1P) && IsValid(Mesh1P))
	{
		Mesh1P->GetAnimInstance()->Montage_Play(Montage1P);
	}

	Server_FireWeapon();
}
```

GetAnimInstance를 통해 원하는 몽타주를 플레이시킬 수 있다
이후 서버에게 알리기 위해 RPC호출

#AnimInStance 는 이 Skeletal Mesh의 애니메이션을 실제로 관리하고 재생하는 객체라 보면된다
```
Mesh1P
  │
  └── AnimInstance
        │
        ├── 현재 애니메이션 상태
        ├── AnimGraph 실행
        ├── BlendSpace 계산
        ├── State Machine
        └── Montage 재생
```
이런것들이 포함된다 함

이후 서버 RPC에서는 단순하게 클라언트로 멀티캐스트로 뿌리기 위한 멀티캐스트 RPC를 호출하고
```cpp
void UCombatComponent::Server_FireWeapon_Implementation()
{
	Multicast_FireWeapon();
}
```

헤더에는 해당 RPC를 이렇게 선언한다
```cpp
	UFUNCTION(NetMulticast, Reliable)
	void Multicast_FireWeapon();
```

이후 멀티캐스트를 받는 함수에서는 1인칭과 동일하게 3인칭 몽타주를 재생하는 작업을 함
나중에 if쪽 즉, 내 캐릭터일때 뭔가 작업할게 있어서 우선 분기를 따로 나둠
```cpp
void UCombatComponent::Multicast_FireWeapon_Implementation()
{
	APawn* OwnerPawn = Cast<APawn>(GetOwner());
	if (OwnerPawn->IsLocallyControlled())
	{
		// My Character
	}
	else
	{
		if (!IsValid(CurrentWeapon) || !IsValid(WeaponData)) return;
		UAnimMontage* Montage3P = WeaponData->ThirdPersonMontage.FindChecked(CurrentWeapon->GetWeaponType()).FireMontage;
		USkeletalMeshComponent* Mesh3P = IPlayerInterface::Execute_GetMesh3P(GetOwner());

		if (IsValid(Montage3P) && IsValid(Mesh3P))
		{
			Mesh3P->GetAnimInstance()->Montage_Play(Montage3P);
		}
	}
}
```

그럼 이제 발사버튼을 클릭할떄 몽타주를 플레이시킬 준비가 끝났다.

근데 테스트 하기전 우리는 대부분 디폴트 슬롯 몽타주를 사용하고 있는데 3인칭 발사 몽타주를 보면 디폴트 슬롯이 아니라 다른 슬롯을 사용하고 있다
