# 이유
# 1. Post Process Volume이란?

**Post Process**는 말 그대로

> **"렌더링이 끝난 화면에 마지막으로 적용하는 효과"**

입니다.

예를 들어

```
3D 씬 렌더링 완료
      ↓
후처리(Post Process)
      ↓
최종 화면
```

여기서 적용되는 것이

- Auto Exposure
- Bloom
- Motion Blur
- Depth of Field
- Color Grading
- Vignette

등입니다.

즉,

**PostProcessVolume은 이 후처리 효과를 어느 영역에 적용할지를 결정하는 볼륨**입니다.

---

# 2. Volume이란?

언리얼에서 **Volume**은

> "어떤 공간(영역)"

을 의미합니다.

예를 들어

```
───────────────
|             |
| Volume      |
|             |
───────────────
```

플레이어가 이 안으로 들어오면

- 안개 적용
- Post Process 적용
- Physics 설정 변경

등을 할 수 있습니다.

즉, **공간에 효과를 부여하는 영역**입니다.

---

# 3. Brush란?

Volume도 하나의 박스입니다.

Brush는 그 박스의 크기입니다.

예를 들어

```
□□□□□
□     □
□     □
□□□□□
```

Brush Size를 키우면

```
□□□□□□□□□□□□□□
□              □
□              □
□□□□□□□□□□□□□□
```

처럼 됩니다.

---

그래서

> **Brush를 맵 전체를 덮도록 변경**

이라는 말은

```
맵 전체
┌─────────────────────────┐
│                         │
│   PostProcessVolume     │
│                         │
└─────────────────────────┘
```

이 되게 만드는 것입니다.

즉,

**맵 어디를 가든 Post Process가 적용됩니다.**

---

# 4. Exposure란?

카메라의 **노출(Exposure)** 입니다.

현실 카메라도

- 셔터
- 조리개
- ISO

에 따라 밝기가 달라집니다.

언리얼도 똑같이

```
노출 ↑
→ 화면 밝아짐

노출 ↓
→ 화면 어두워짐
```

입니다.

---

# 5. Auto Exposure란?

사람 눈을 흉내낸 기능입니다.

예를 들어

```
어두운 방
   ↓
밖으로 나감
```

처음엔

```
너무 밝다!!
```

몇 초 후

```
눈이 적응
```

합니다.

반대로

```
밝은 밖
 ↓
어두운 방
```

처음엔

```
아무것도 안 보임
```

조금 지나면

```
점점 잘 보임
```

이 됩니다.

언리얼이 이것을 자동으로 계산합니다.

---

# 6. Metering이란?

**Metering = 밝기를 측정하는 방법**

입니다.

즉,

```
현재 화면이 얼마나 밝은가?
```

를 계산하는 알고리즘입니다.

---

# 7. Auto Exposure Basic

Metering Mode를

```
Auto Exposure Basic
```

으로 바꾸면

비교적 단순하게

> **화면 전체 평균 밝기**

를 보고 노출을 계산합니다.

예를 들어

```
████████████
████████████
████████████
```

화면 전체 평균을 구해서

```
조금 밝게 해야겠다.
```

를 결정합니다.

---

반면

Histogram 방식은

```
검은색 60%
회색 30%
하얀색 10%
```

처럼

밝기 분포까지 계산합니다.

더 정확하지만 계산량이 조금 더 많습니다.

---

# 8. 왜 플레이하면 점점 밝아질까?

원래는

```
게임 시작

↓

카메라 노출 초기값

↓

현재 화면 분석

↓

조금 더 밝게

↓

다시 분석

↓

조금 더 밝게

↓

적정 밝기
```

이 과정을 거칩니다.

그래서

```
어둠

↓

조금 밝아짐

↓

더 밝아짐

↓

완성
```

처럼 보이는 것입니다.

---

# 9. 그런데 왜 저 설정을 하면 해결되지?

당신이 적은 순서를 보면

```
PostProcessVolume 생성

↓

맵 전체를 덮음

↓

Auto Exposure Basic 사용
```

이렇게 되어 있습니다.

핵심은 **맵 전체에 동일한 노출 설정이 항상 적용되도록 만드는 것**입니다.

Post Process Volume이 맵 일부에만 있거나 없으면 플레이 시작 시 기본 노출 설정으로 시작했다가, 나중에 볼륨의 영향을 받아 밝기가 바뀔 수 있습니다.

다만 **"처음부터 밝기가 고정"되게 하려면** `Metering Mode`를 `Auto Exposure Basic`으로 바꾸는 것만으로는 충분하지 않습니다. 여전히 자동 노출은 동작합니다.

보통은 추가로 **Exposure의 `Min EV100`과 `Max EV100`(또는 엔진 버전에 따라 `Min/Max Brightness`)를 같은 값으로 설정**하여 자동 노출 변화 자체를 막습니다. 그러면 플레이 시작 시 밝기가 변하지 않고 처음부터 일정한 밝기로 렌더링됩니다.

### 한 문장으로 정리하면

- **Post Process Volume**: 후처리 효과를 적용할 공간
- **Brush**: 그 공간의 크기
- **Exposure**: 카메라 밝기(노출)
- **Metering**: 화면 밝기를 측정하는 방식
- **Auto Exposure Basic**: 화면 평균 밝기를 기준으로 자동 노출을 계산하는 비교적 단순한 알고리즘
- **맵 전체를 덮는 이유**: 플레이어가 어디에 있든 동일한 후처리 설정을 적용하기 위해서입니다.
